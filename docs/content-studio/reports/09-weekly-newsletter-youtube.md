# 9단계 완료 보고서: 주간 뉴스레터와 유튜브 대본

- 완료일: 2026-09-19
- 기본 출력: `var/content-studio/weekly/<시작일>_<종료일>/`

## 수행 내용

- 지정한 종료일을 기준으로 7일간의 검증 완료 이벤트만 조회한다.
- 같은 티커의 직전 공식 이벤트와 비교해 배당 증감률을 계산한다.
- 다음 세 파일을 한 번에 생성한다.
  - `facts.json`: 원문 URL을 포함한 사실 고정 데이터
  - `newsletter.md`: 주간 뉴스레터 원고
  - `youtube-script.md`: 오프닝, 종목별 본문, 클로징으로 구성된 내레이션 대본
- 증감률 절댓값이 큰 이벤트부터 배치해 중요한 변화를 먼저 보여준다.
- `needs_review` 이벤트는 자동 원고에 포함하지 않는다.

## 생성 원칙

- 숫자, 날짜, 티커와 공식 URL은 SQLite 값에서 직접 가져온다.
- 확인되지 않은 원인이나 전망을 자동으로 만들어내지 않는다.
- 총수익률, ROC, 기준가 변동과 세금을 함께 확인하라는 고지를 포함한다.
- 이후 AI 문장 다듬기를 붙이더라도 `facts.json`을 변경 불가능한 근거 입력으로 사용할 수 있다.

## 실행 방법

```powershell
npm run content:weekly
```

특정 주차는 `python scripts/content_pipeline/weekly_digest.py --week-ending YYYY-MM-DD`로 생성한다.
