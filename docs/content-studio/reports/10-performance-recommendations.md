# 10단계 완료 보고서: 성과 누적과 주제 추천

- 완료일: 2026-09-19
- 입력 템플릿: `docs/content-studio/performance-import-template.csv`
- 대시보드 출력: `public/content-studio/recommendations.json`

## 수행 내용

- SQLite에 플랫폼별 콘텐츠 성과를 누적하는 `content_performance` 테이블을 추가했다.
- 토스, 네이버, 유튜브 등 플랫폼별 조회, 좋아요, 댓글, 클릭, 구독 증가, 시청 시간과 제작 시간을 CSV로 가져온다.
- `platform + content_key`를 고유 키로 사용해 재수집 시 중복 대신 최신 수치로 갱신한다.
- 주제별 성과 점수를 계산하고 다음 제작 후보를 높은 순서로 내보낸다.
- 대시보드에 `다음 콘텐츠 추천` 패널을 연결했다.

## 점수 구성

- 도달 25점: 로그 조회 수
- 참여 30점: 좋아요 + 댓글 2배 + 클릭
- 전환 20점: 조회 대비 구독 증가
- 시청 15점: 조회당 시청 시간
- 최신성 10점: 45일 감쇠
- 신뢰도 보정: 표본이 작은 콘텐츠의 과대평가 방지

주제별 점수는 조회 수의 제곱근을 가중치로 합산한다. 결과에는 표본 수, 누적 조회, 관련 티커, 최고 플랫폼과 추천 이유가 함께 남는다.

## 실행 방법

```powershell
npm run content:performance -- docs/content-studio/performance-import-template.csv
npm run content:recommend
```

## 운영상 주의

이 점수는 투자 추천이 아니라 **콘텐츠 제작 우선순위**다. 조회 수만 높은 낚시성 주제를 과도하게 밀지 않도록 참여, 전환, 시청과 표본 신뢰도를 함께 사용한다. 플랫폼에서 내보낸 실제 성과 CSV를 넣기 전에는 추천 목록이 비어 있는 것이 정상이다.
