## 예외 및 재시도

- Roundhill은 일부 선언일에 추적 행이 없었으나, 확인된 공식 Cboe 원문 1건에서 23개 이벤트를 반영했다. 나머지는 재시도 가능 실패로 기록했다.
- SCHD는 공식 사이트가 HTTP 403을 반환해 아직 이벤트가 없다. 재시도 가능으로 기록했다.
- YieldMax 뉴스 목록의 GlobeNewswire HTTP 링크는 HTTPS canonical URL로 정규화했다. 수집 환경의 응답 시간 제한으로 이번 실행에서 완료되지 않아 재시도 대상으로 남겼다.
- `needs_review` 이벤트는 콘텐츠 생성 기본 대상에서 제외된다.
