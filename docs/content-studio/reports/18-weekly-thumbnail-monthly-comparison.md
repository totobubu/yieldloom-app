# 18. 주배당 썸네일 금액 비교 및 월별 표

## 구현

- 모든 콘텐츠에 `직전 $금액 → 이번 $금액`과 퍼센트 증감을 함께 표시한다.
- 주배당으로 판단되는 티커는 발표일 이전·당일의 실제 `public/data` 배당 이력을 사용해 최근 4개월 월별 표를 추가한다.
- 각 월에는 월 합계와 주별 지급 금액을 색상 칩으로 표시한다.
- `expected: true` 예정값과 발표일 이후 값은 표에서 제외한다.
- 월별 행의 실제 배당 횟수가 2회 미만이면 월배당/분기배당으로 보고 주배당 표를 표시하지 않는다.

## 안정성 수정

- 기존 bundle 재생성은 SQLite row ID가 아닌 bundle 디렉터리의 `선언일 + 티커`로 이벤트를 찾도록 변경했다.
- DB 재구축 뒤 ID가 달라져 다른 티커 콘텐츠가 덮이는 문제를 방지한다.

## 예시

- TSLY 2026-09-16 카드: 직전 `$0.2153` → 이번 `$0.2127`, `-1.2%`.
- 월별 합계: 26.09 `$0.6342`, 26.08 `$0.8244`, 26.07 `$1.2714`, 26.06 `$1.1649`.

## 검증

- 단위 테스트는 금액 비교 문구, 월별 표 렌더링, stale ID bundle 재생성 방지를 확인한다.
- 기존 51개 bundle을 재생성하고 PNG를 강제 재렌더링했다.
