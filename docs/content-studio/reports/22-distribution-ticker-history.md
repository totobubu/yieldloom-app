# 22. 티커별 최신 배당 이력과 상세 레이어

## 완료 범위

- 배당 이력 목록은 티커별 최신 공식 이벤트 1건만 표시한다.
- 운용사 탭과 티커 검색을 함께 적용했다.
- 티커 클릭 시 PrimeVue Dialog에서 전체 과거 기록 표와 최근 12회 배당금 변화 차트를 표시한다.
- 과거 이력 JSON은 상세 레이어를 열 때만 별도 요청한다.

## 데이터 원칙

- 목록 제외는 화면 표시 정책일 뿐 SQLite 원장 또는 공식 원문을 삭제하지 않는다.
- 최신 이벤트는 배당락일과 이벤트 ID 기준으로 결정한다.
