# 18차 수용 기준 감사와 완료 계획

현재 작업은 **일부 구현·합성 검증 완료, 전체 디자인 수용 및 실계좌 검증 미완료**다. 운영 배포하지 않았다. 17차까지의 `0/14`는 개선량이나 측정된 불량률로 사용할 수 없다. 아래는 그 원인과 남은 최소 작업 단위다.

## 판정 도구에서 발견한 문제

기존 `validate-stitch-evidence.mjs`는 화면마다 `pixelParity: 'fail'`, 전체 `visualAcceptance: 'fail'`을 상수로 기록했고 `--require-parity`가 있으면 조건 없이 exit1이었다. 따라서 원본 해시·뷰포트·캡처 건강 검사는 실제 검사였지만, 시각 FAIL은 자동 비교로 산출한 결과가 아니었다. 알려진 차이를 보수적으로 미승인으로 표시하는 장치였고, 17회 개선 추적 지표로는 부적절했다. 이를 명확히 설명하지 않은 이전 보고를 정정한다.

18차는 픽셀 판정을 `not-scored`로 바꾸고 화면 시각 판단은 `screen-status.json`의 기록된 검토 결과를 읽어 구분한다. 게이트도 미충족 조건에 따라 실패하도록 바꿨다. 현재 검토 기록은 여전히 FAIL이고, 이 도구 자체로 셸 시각 검토·원본 상태 전수·실계좌를 인증할 수 없으므로 strict gate는 계속 exit1이다. 이 변경은 수용 기준을 낮추거나 화면을 자동 합격시키는 변경이 아니다.

다음부터 화면별로 세 가지를 별도로 기록해야 한다: (1) 대응 영역의 요소·반응형 구조·치수 결함, (2) 실제 제공값/기간/결측/권한과 원본 가상 예시의 정당한 차이, (3) 추가 기능·누락 프레임의 수용 미검토. 렌더링 차이와 실제 금융 값을 같은 픽셀 실패에 합산하지 않는다. 기존 원본/원본 PNG·전체42쌍은 그대로 보존한다. 필요한 경우 **별도의 검증 전용 DOM 재생**으로 문구만 통제하며 실제 앱/금융 데이터와 원본 파일은 수정하지 않는다.

## 측정 근거와 공통 원인

`/workspace/stitch-v2-evidence/checks/phase18/geometry-audit.json`은14종×3폭의 원본/구현 제목·영역 치수다. 원본과 앱의 제목 태그/순서가 다르므로 배열 인덱스로 다른 제목을 자동 대조하지 않는다. 정상 본문이 숨은 h1을 가진 페이지가 있어 첫 도구 실행은 h1 대기에서 실패했다. 기존 화면별 준비 요소를 기다리도록 수정해42개를 다시 측정했고 JS/원격 정적 자산 오류0이다. 관련 최초 실패 로그도 보존한다.

- **공유 종목 헤더의 탭 구분 누락:** 구현의 공통26px/36.4px/800은 배당 원본36px/44px/700, 공유 원본24px/32px/600과 달랐다. 3폭 모두 같은 차이였다. 해당 두 탭만 원본 자간까지 복원했다. 상세/시세의26px 및 데이터·레이아웃·API는 변경하지 않았다. `headlines-after/geometry-audit.json`의6개 재측정으로 font-size/line-height/weight/tracking 일치를 확인한다. 이것은 제목 부분 PASS이며 화면 전체 PASS가 아니다.
- **전역 제목 line-height1.4:** 검색30.8 대33px, 비교33.6 대36px, 요약22.4 대24px, 캘린더/분석28 대30px다. 보유/자산관리의 대표 제목은 이미32/44px로 원본과 같다. 모든 제목을1.5로 바꾸면 기존에 맞는 Hanken 토큰28/32/44px 영역을 다시 바꿀 수 있어 일괄 수정하지 않았다. 이는 대부분1.6~2.4px의 P2 결함이며 큰 화면 높이 차이의 주원인이 아니다.
- **실제 구조와 부가 기능:** PC 분석 캡처1332 대4510px 중 기존 `.additional-insights`만2323.88px다(Tablet2778.39/Mobile4324.72px). 부가 기능을 제거해서 높이를 맞출 수 없고 대응하는 핵심 분석 구역과 별도로 조립해야 한다. 단순 총높이 차이3178px 전부를 CSS 불량이라고 할 수 없다. 원본 최소높이·행수·내용차이도 있으므로 나머지854.12px를 곧바로 동일 원인으로 귀속하지 않는다.
- **공유 편집기:** PC `.share-selector`697.5px, 미리보기 열1307.5px, 도구 열729.58px다. 원본과 다른 선택기/제어 패널 구조가 주요 수정 대상이다. 사용자 승인한 최근1건과TTM 두 지표는 보존한다. 하나의 축소/전역 글꼴/고정높이 변경으로 해결하지 않는다.

현재 확실한 큰 차이는 공유 편집기, 가격 차트/도구, 분석 핵심+추가도구 조립, 일정 도구/상세 조립, 비교 결과표다. 검색·보유·자산관리의 제목/카드 일부는 이미 치수 일치한다. 이 세 화면을 큰 결함과 동등한 `FAIL 한 표`로만 취급하면 우선순위가 왜곡된다.
