# 공유 지표: 사용자 결정과 구현 계약

사용자는 ‘1,2. 전부 진행’으로 두 작업을 모두 지시했다. 최신1건 카드의 금융 의미·`summary` 파일/프리셋 호환성을 유지하며 새 디자인을 적용했고, `ttm-summary`를 여섯 번째 템플릿으로 추가했다. 기존 카드가 사라지거나 원본 예시 값으로 바뀌지 않는다.

고정 합성 DEMO-A(운영 수치 아님)의 렌더링/내보내기는 최신1건$0.16·예상 세후$0.136·1건 비율0.32%, 12개월$1.04·2.08%다. 두 카드가 함께 든 ZIP에서 기존`demo-a_summary.png`와 새`demo-a_ttm-summary.png`를 확인했다.

## 12개월 완전성

`src/services/thumbnail/trailingDividendSummary.js`는 기존`calculationCoverage`를 재사용한다. 최초/최종 행이 오래됐다는 이유로 완전하다고 판단하지 않는다.

- `collectionCoverage.dividends` 또는 sourceStatus의 동일 메타데이터가 요청 기간 전체를 complete로 확인해야 한다.
- 누락 구간의 두 별칭(missingIntervals/gaps), 검토 필요·분할 조정·중복·금액 오류·통화 상충·잘못된 날짜/메타데이터는 수치를 보류한다.
- 미래/유효하지 않은 기준일·통화 미확인은 보류한다. 미래/예측 배당은 합산하지 않는다. 기준일의 시장 날짜 해석은 기존 dividendMarketDate를 재사용한다.
- 배당 합계가 확인돼도 기준 시세가 없으면 연 배당률은 미확인이다.
- 불완전/검토 데이터는 합계·연 배당률·막대를0으로 바꾸지 않는다. ‘미확인’ 및 보류 이유를 표시하고 ZIP 측정값도 null이다.
- 무배당0은 명시적 완전성 증거가 있고 해당 기간의 이벤트가 없을 때만 표시한다.
- 4개 막대는 위12개월을 나눈3개월 구간이다. 달력 분기로 오해하지 않도록 각 시작/끝과 ‘달력 분기가 아님’을 표시한다. 임의Q1~Q4 수치를 채우지 않는다.

화면 상단의 기존12개월 수치도 같은 증거 기반 결과를 사용한다. 완전성 메타데이터가 없으면 오래된 이력이 있어도 미확인으로 표시한다. 실제 수집 상태를 변경하거나 완전성 증거를 만들어 넣지 않았다. 합성 테스트에만 명시적 coverage를 제공했다.

## 기능 보존과 증거

기존5종 ZIP/PNG, 프리셋·톤·720정사각형·모바일·다크 독립성을 재검증했다. 새 카드의 기간/완전성/세전/가격 기준은 PNG·복사·ZIP manifest.measurement에 남긴다. TTM 프리뷰의 게시 문구를 따로 표시하고, 개별 PNG를 내려받은 뒤 재복사하는 문구도 마지막 파일의 지표와 일치시켰다.

- `ttm-card/`: 완전/불완전/검토/완전 무배당0 ×3폭의 실제720px PNG 및 두 카드 manifest.
- `ttm-variant/`, `ttm-variant-comparisons/`: 원본 TTM 화면과 실제12개월 프리뷰3폭 비교. 기본 최신1건 프리뷰와 구분해 클릭 상호작용을 기록했다.
- `tests/trailing_dividend_summary.test.mjs`:17개 계산/불완전/윤년/분할/통화/메타데이터 계약.
- `tests/stitch-ttm-card.browser.mjs`:12상태의 PNG/ZIP·기존 카드 보존·기간별 복사·오버플로 없음.

증거 루트는 `/workspace/stitch-v2-evidence/`다. 실제 계좌·실제 전체 시장 이력·운영 배포 검증과 합성 테스트를 혼동하지 않는다.
