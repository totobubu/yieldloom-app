# 공유 지표: 추가 범위 선택

**현재 유지하는 것:** 최근 배당 1건·12개월 요약 두 카드와 기존 비교·진입·재투자 계산입니다. 디자인을 적용하면서 지표 이름이나 실제 값을 다른 의미로 바꾸지 않습니다.

결정할 것은 아래 **새 지표를 별도 카드로 추가할지**입니다. 기존 기능을 유지한 디자인 적용은 이 결정과 관계없이 진행할 수 있습니다.

| 새 지표 | 현재 기능과의 차이 | 추가에 필요한 조건 |
|---|---|---|
| 여러 종목의 세전 TTM 배당률 비교 | 현재는 같은 종목의 직전·최신 배당 1건을 비교 | 각 종목의 동일한 12개월 전체 이력·완전성, 동일 기준의 가격/기준일, 통화 구분과 기업행사 검증. 부족한 종목은 수치를 표시하지 않음 |
| 현재 세전 TTM 기준 과거 매수가별 YOC | 원본은 ‘현재 TTM 배당금 ÷ 과거 매수가’. 현재 기능은 각 표본 기간의 세후 배당금/매수가이며 초기 누적 모드도 있음 | 검증된 현재 TTM과 과거 가격, 분할 전후 단위의 일치, 표본일/기간 명시. 실제 과거 수령액·당시 알려진 배당률로 표현하지 않음 |
| 지수 수준·추적 지표·지수 배당률 | 현재는 공통 기간의 초기 $10,000·배당 재투자 총수익을 비교 | 실제 지수 공급 자료와 ETF/지수의 동일 통화·수익 기준. ‘추적’은 기간 수익률 차이인지 수익률 차이의 변동성인지부터 정의해야 함. 지수 배당률도 별도 검증 자료 필요 |

- **선택 A — 기존 지표를 유지하고 디자인만 적용:** 현재 진행 방식입니다. 원본과 의미가 다른 부분은 실제 정의를 명시합니다.
- **선택 B — 기존 지표를 보존하면서 선택한 새 지표 추가:** 위 세 항목 중 추가할 범위를 정합니다. 자료·정의가 확보되기 전에는 미구현으로 남기며 가상 값이나 기존 수치로 대신하지 않습니다.

B를 선택하더라도 즉시 계산·데이터 연결이 완료되는 것은 아닙니다. 지수의 추적 지표 정의는 별도 확정이 필요합니다. 운영 반영은 전체 검증 후에 진행합니다.
