# 23차: 모바일 월 표시와 세 비교 화면의 공통 밀도

공유 지표 추가 결정과 독립적인 UI를 수정했다. 실제 Stitch 원본 캘린더 `fc276eb9388a48909296fb018f60771b`, 기초자산 `41abb021992c4d1a9570cd5a03313cb6`, 유사 ETF `ef89e781a5c54636b82ad0407924c21f`, 테마 `05b463a83d564c34886e0f9c018ac2a3`의 HTML/PNG를 사용한다. 원본/구현은1280/768/390·DPR2·고정 합성 자료로 비교한다. 운영 자료나 금융 정의·계산·권한을 바꾸지 않았다.

## 캘린더: 한국어 월과 실제 입력 기능

영어 기본 month 입력을 설치된 PrimeVue4 DatePicker의 월 선택기로 바꿨다. PC·Tablet은 `2026년 11월`, Mobile은 `2026.11`로 표시한다. 전체 한국어 월은 달력 제목과 입력 title에도 표시한다. 현재 월 표시와 임의 월 입력/선택·1900~2100 범위·이전/다음·오늘·연간 보기를 유지한다. 로컬 연·월을 기존 `YYYY-MM`으로 넘기며 새로운 API나 UTC 변환을 추가하지 않는다. resize 구독은 해제한다.

모바일에서도 원본과 같은 `2026년 11월`을 한 줄 입력에 넣은 첫 수정에서는 월이 잘렸다. 최초 캡처 `checks/phase23/after/calendar-390.png`와 폭 진단을 보존한다. 기존 동작 검사는 문자열 값·넘침만 확인해 이 잘림을 놓쳤다. 새 검사에 실제 글꼴의 canvas 텍스트 폭과 입력의 사용 가능 폭 대조를 추가했다. 숫자 월은 생략하지 않는다.

원본은80.125px 폭의 읽기 전용 span이 두 줄로45px에 걸쳐 표시된다. 구현은 실제 편집 가능한 한 줄 월 선택기라 동일한 줄바꿈은 불가능하다. 글꼴 축소나 보이지 않는 입력으로 편집을 방해하지 않고 Mobile만 짧은 날짜 표기를 쓴다. 이 **표현 차이는 남아 있으며** 픽셀 완전 일치로 판정하지 않는다. 전체 원본과 같은 두 줄 편집 UI가 필요하다면 별도의 입력 패턴 설계가 필요하다.

원본 Today 날짜를 가시 문구에도 복원했다. 버튼의 실제 Arial14px/600,12px 좌우 패딩을 적용하고 입력의 전역44px 최소 높이를 제한 범위에서38px로 수정했다. Mobile 월 입력45px·도구 여백으로 외곽을 원본 PC76/Tablet126/Mobile229px와 맞췄다. 원본의 span 폭과 구현의 월 입력 폭·외곽 크기는 측정 JSON에 구분한다.

## 비교 세 종: 공통 Select와 제목

세 원본 모두 단계 필터 제목15px/22.5px, 기준 종목명18px/27px, Select44px, 라벨13px/19.5px, 초기화27px이다. 구현은 제목16px, 기준명16px/25.59px, Select51.59px, 초기화24px였다. 같은 컴포넌트의 해당 속성을 원본에 맞췄다. 라벨과 숫자 배지는 flex로 배치해 인라인 baseline이 필터행을 늘리지 않도록 한다.

전략→방향→배당 상태→주기의 실제 조건 해제, 조회 버튼, 선택 기초자산/ETF/테마, 추가 안내와 결과표/종목 수는 유지한다. 실제 금융 값이나 분류 미확인을 가상의 원본 예시 값으로 채우지 않는다. 조회 전후 안내·실제 표 컬럼/행수·조건 선택지의 차이는 이번 치수 일치와 별개로 남는다.

## 증거와 검증

`checks/phase23/comparison-before`와 `comparison-after`는3화면×3폭의 실제 속성·전체 캡처다. `before`·`width-diagnosis`·`verified`는 캘린더와 분석 회귀 측정이다. 원본 내장 스크립트를 읽기 전용으로 렌더링하고 정적 자산 실패/페이지 오류를 기록한다. 원본이 없는 프레임이나 미생성29종은 만들지 않았다.

최초 회귀에서 제목의 한국어 표기 교체가 실제 템플릿의 줄바꿈과 맞지 않아 `2026-11`로 남은 것을 새 검사가 발견했다. 제품 템플릿을 바로잡았으며 기대값을 약화하지 않았다. 측정 도구의 unused parameter lint 오류도 수정했다. 최초 실패 로그는 보존한다.

최종 검사 수·잔여 치수와 검증 결과는 아래 결과 및 체크포인트 manifest를 따른다. 전체 시각 승인·실계좌 인증/DB/PDF·원격CI·배포는 수행하지 않는다. 미정 peer TTM·세전 YOC·지수 지표는 [결정 요약](METRIC_DECISION_SUMMARY.md)대로 미구현이다. 최근1건/12개월 카드는 유지한다.


최종 실측: 비교3종×3폭의9쌍 모두 필터 제목22.5px·기준명27px·Select44px·초기화27px 높이와 필터 내용 전체PC69.5px/Tablet·Mobile320px가 원본과 같다. `named-comparison-geometry.json`은 지정 속성만의 일치이며 화면 전체 시각 승인이 아니다.


최종 관련 브라우저8개(월 입력/기존 캘린더·비교 탐색/캐스케이드·우선 패널·데이터 계약·콘텐츠 폭·셸)와 단위22개가 통과했다. 월 입력은 최종 제품 변경 후 실제 팝업 선택/뷰포트 경계·회전·전체 글자 폭까지 추가 검사해 재통과했다. 우선 패널39상태를 갱신했다. 셸은 공개/합성관리자 각각4폭의8문맥 회귀이며 원본12개 상태 비교를 새로 만들었다는 뜻이 아니다. 기존12개 비교는 보존한다. 셸 스위트의 같은 파일명이 공개→관리자 캡처를 덮어쓰므로 최종8개 PNG만 별도 보존한다. 이전22차 보고의 ‘셸12상태 다시 기록’ 표현은 해당 구분이 없었으며 새12개 비교로 읽어서는 안 된다.

build/type 통과, lint오류0·경고54개, diff 공백 검사 통과다. 기본47/총57 브라우저 스위트는 CI 구성 수이며 이번8개와 다르다. 전체 마지막 회귀 기준17차를 유지한다. 새 기본12개 캡처/전체42개 진단 비교와 기존 원본30기록의 증거 무결성은 통과하지만 엄격 수용 게이트는exit1이다. 전체시각/실계좌 검증·운영 배포를 완료로 표시하지 않는다.
