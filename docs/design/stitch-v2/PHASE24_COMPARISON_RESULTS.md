# 24차: 비교 결과표·카드와 안내 영역

기초자산 `41abb021992c4d1a9570cd5a03313cb6`, 유사 ETF `ef89e781a5c54636b82ad0407924c21f`, 테마 `05b463a83d564c34886e0f9c018ac2a3`의 실제 원본을1280/768/390·DPR2에서 대조했다. 기존 금융 계산·수익률 기간·권한·조회 흐름과 최근1건/12개월 공유 카드·미정 지표는 변경하지 않았다. 새 원본이나 운영 데이터는 생성하지 않았다.

## 구조와 표시 수정

PC 결과표는 기존9열/row header 의미를 유지하면서 원본960px 최소 폭·바깥12px 테두리 프레임·헤더14px 16px/본문16px 패딩·수직 중앙 정렬을 복원했다. 기존 ‘한눈에 비교’/주의문은 별도로 보존하고 테이블 프레임의 추가20px 안쪽 여백을 제거했다. 가로 스크롤 영역에는 키보드 포커스와 이름을 붙였다. 티커/종목명·기준·전략/방향/배당 상태·상세 링크의 원본 계열 서식을 사용한다. 실종목의 기준일·배당금·배수 미확인·근거 상태는 삭제하지 않았다.

Tablet/Mobile은 원본과 같은 헤더/상세 링크,4개 필드 격자(기초자산 또는 테마 근거·전략·배당 상태·주기),3개 조회 지표 줄,출처 영역으로 재조립했다. 원본에 없는 기존 최근 주당 배당금은 별도 블록으로 유지했다. 회사명·공식 근거 링크/검증 대기 상태·기준일도 보존했다. 실제 근거가 없는 연결을 공식 검증으로 표시하지 않았다. 카드의 원본 패딩16px·gap12px, 필드 격자padding12/gap10, 지표3열gap8/padding8px 4px와 점선 구분, footer위8px를 복원했다.

조회 전의 `미확인`은 명시적인 `조회 전`으로, 실행 중은 `조회 중`으로 구분한다. 기존 detailed/pending 상태만 사용한다. 조회 후 자료가 없으면 여전히 `미확인`이고0을 대입하지 않는다. 정상0%는0%로 보존한다. 공급자가 unavailable로 표시한 값은 값이 있어도 기존 comparableMetric 규칙으로 제외한다. 해당 없음인 일반주식 보수도 유지한다. 조회/캐시/취소·필터/페이지 무효화는 변경하지 않았다.

원본 조회 안내의12px/18px 줄 높이·44px 실행 버튼·24px 좌우 패딩을 적용했다. 실제 서비스에 ‘정적 시안이라 조회하지 않는다’는 원본 문구를 복사하지 않고 실제 미조회/같은 기준 비교와 **가격 하락은 배당 제외 가격 기준**이라는 설명을 유지한다. 유사 ETF 안내는 원본13px/19.5px·12px 16px 패딩·6px 모서리로 조정했다. 추가 비교 범위/테마 분류 안내도 남긴다.

## 증거와 테스트 해석

`checks/phase24/comparison-{before,after,verified}`에3화면×3폭 캡처와 치수를 남긴다. 원본과 구현의 같은 viewport/font-ready·고정 합성 자료를 사용한다. 별도로 기본9개 콘텐츠 캡처와42개 진단 비교를 갱신한다. 데이터·행수·추가 기능이 포함된 전체 픽셀 비율은 합격률이 아니다.

새 결과 검사는3화면×3폭에서 미조회/명시 조회·정상0/자료 미확인·실제 상세 경로·검증 대기·모바일 구조·개인 API 미호출·쓰기0·넘침/오류0을 확인한다. 테마 화면의 실제 합성 구성종목은DEMO-E이므로 A/B를 억지로 포함하지 않는다. 첫 검사에서는 공통 fixture의 loadSecurityInsights가 항상null을 반환해 HTTP fixture가 사용되지 않았다. 제품 계산을 바꾸지 않고 공통 fixture에 기본값{}인 선택적 insightsBySymbol을 추가했다. 기본 캡처 fixture는 그대로null을 반환한다. 서비스 경계의 합성 검사이며 실제 지표 공급 검증이 아니다. 기존 비교 탐색 검사는 실제 조회 서비스에 대한 HTTP 합성 검사로 별도로 유지한다. 최초 실패 로그를 보존한다.

## 정확한 잔여 범위

원본은 가상의3종목·예시 검증 상태이며 구현은 실제 서비스 규칙을 쓰는 고정 합성4종목/테마1종목이다. 배당금/배당락일·배수/근거·기간 메타데이터와 기존 최근 배당 블록이 추가되므로 동일한 전체 카드/행 높이를 주장하지 않는다. 원본의 일반 ‘수익률/수수료/가격 하락’보다 구현은1년 총수익률·운용 보수·기간 가격 변화/최대 하락을 구체적으로 구분한다. 제목을 짧게 만들려고 지표 정의나 기간을 삭제하지 않았다.

원본 없는 팝업·미생성29종, 미정 peer TTM/세전YOC/지수 지표, 실제 인증/계좌/PDF/DB·원격CI·전체 시각 승인·배포는 미완료다. 최종 수치와 검증 결과는 아래 기록 및 checkpoint manifest를 따른다.


수정 중 공통 표 본문의 font-weight400이 기존 상대 우위750을 덮는 것을 발견했다. `.is-best`의 실제 computed font-weight를 검사해 실패를 재현하고 해당 표시를 복원했다. 최초 로그는 `highlight-first-attempt.log`에 남긴다. 계산이나 비교 가능 기간 판정을 바꾸지 않았다. 카드 필드의 기존 실제 링크는 원본 본문색으로 맞추되 hover/키보드 focus에서는 링크임을 표시한다.

실측: PC 원본/구현 헤더48px·padding14px 16px, 본문padding16px·수직중앙·14px/21px, 최소폭960px가 같다. Tablet/Mobile 필드 격자는 원본/구현212px·padding12px/gap10px다. 유사 ETF 안내 높이는45.5/45.5/65px로 동일하다. 조회 안내는PC104px/Mobile140px로 같지만 Tablet은 실제 추가 설명이 한 줄 더 있어104/122px다. 원본 예시의 첫 본문행77~77.8px와 구현97.8px(테마112.1px), Mobile 카드428px/571.2px는 다르다. 추가 배당금/일자·배수/분류근거·회사/검증/기간 정보를 삭제해 높이를 맞추지 않는다. 이를 전체속성일치나전체시각승인으로기록하지않는다.


지정한9쌍의 원본 속성 비교는 `named-result-geometry.json`의 전부 통과다. 행/카드 전체 높이는 판정에 포함하지 않고 위 잔여로 남긴다. 조회 후 원본은 정적 시안의 실행하지 않는 버튼/조회 전 상태뿐이며 검증된 별도 조회 결과 프레임이 없다. 구현의 조회 전·후18개 PNG와9개 결과 JSON은 **합성 구현 상태 증거**이며 원본 상태18개와 일치한다고 표현하지 않는다. 처음 조회 후 캡처에는 클릭으로 인한 스크롤 위치가 반영돼 고정 헤더가 전체 이미지 중간에 나왔다. 최종 상태 캡처는 fonts.ready와 scrollTop0 후 같은 viewport/DPR2로 다시 만들었다.
