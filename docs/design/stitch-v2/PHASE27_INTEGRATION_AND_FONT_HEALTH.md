## 캡처 방법의 실질적 보정

기존 HTTPS 합성 차단이 나중에 등록돼 정적 자산 처리기를 가리고 있었다. 콘텐츠/셸/감사/상세 측정에서 합성 계약을 먼저 설치하고 허용된 정적 자산 처리기를 그 뒤에 설치했다. 실제 외부 API는 계속 차단하며 공개 글꼴·정적 CDN만 기존 허용 목록으로 읽는다. 서비스 보안 설정/계좌 데이터 접근을 변경하지 않았다.

`document.fonts.check()`는 미등록 글꼴도 fallback으로 참일 수 있다. 콘텐츠 캡처는 실제 등록된 FontFace의 family/weight/status를 기록하는 v2 증거로 바꿨다. 검사기는 필요한 화면의 Hanken/Noto/숫자용 JetBrains Mono의 실제 loaded 상태를 확인한다. 현재 Noto42개, 필요한 Hanken 화면27개, 평가/보유/자산관리 Mono9개가 확인됐다. 미사용 글꼴을 전부 loaded로 요구하지 않는다.

새 콘텐츠42쌍·셸12상태와 비교를 생성했다. 네이티브 기기별 PNG가 없는 원본은 원본 HTML을 같은 viewport/DPR로 재렌더한 비교이며 필드에도 명시했다. 원본 PNG/HTML의 보존 해시는 별도로 검사한다. 새 글꼴 조건의 진단 비율을 과거 대비 개선율이나 시각 합격률로 해석하지 않는다.
