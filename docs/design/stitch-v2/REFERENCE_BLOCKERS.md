## 데이터 차이를 UI 미구현과 혼동하지 않기

실제/합성검증자료의가격·기간·ROC·누락·권한·계좌명은Stitch가상예시와다르다. 이를가상값으로대체하지않는다. 원본CSS는내용에따른가변높이다. 16차의보유모바일16px차이를DATA만의차이로설명한것은잘못됐다. 17차동일문구재생에서원본276px/구현292px가남아원본에없는메타행gap12px를발견했다. 원본의첫두행gap0/center와마지막행gap8/start를복원한후동일문구원본/구현은Tablet·Mobile모두276px다. 이항목은수정완료이며누락디자인차단이아니다. 원본파일/CSS/금융수치는수정하지않는다. 해당데이터재생은원본PNG대신사용하거나전체시각PASS로확대하지않는다.

사용자가승인한최근1건과12개월요약카드는기간/의미를구분해유지한다. 원본에예시수치가있다고불완전한12개월값·미확인ROC·환산합계를0이나완전한값으로만들지않는다. 권한을가상‘편집가능’으로바꾸지않는다.

## 원본이 있어 계속 수정 가능한 UI

원본이있는일반외형은SCREEN_STATUS.md의UI항목이며미완료이다. 이를위BLOCKED_DESIGN/계약사유로재분류하지않는다. 남은대표위치는상세의자료상태/피드백밀도,시세의기간/차트도구,공유의선택·프리뷰/복사도구,비교의기준카드/결과표,요약의명의자/계좌범위조립,배당캘린더의기간도구·안내,분석의월서식/추가도구,자산관리의실제관리영역과로컬탭,등록의입력·확인상태간격이다. 새디자인이나사용자결정때문에이모든항목이막혔다고주장하지않는다.

17차는이중누락된시세이벤트열/카드,검색제목의전체폭/페이지버튼/모바일칩,비교3종의기본범위칩을우선수정한다. 원본없는프레임에는추가디자인을하지않으며검증결과·잔여범위는17차체크포인트와대조표에남긴다. 전체14종의시각완료를주장하지않는다.
