# 세 항목의 검토 결론과 PC 조립 선택지

12차에서 실제 원본 치수를 다시 측정했다. **현재 UI 적용을 계속하기 위해 사용자에게 추가로 물을 사항은 없다.** 원문 미지원 표시와 기존 권한 유지를 채택하고, PC는 원본이 명시한 본문 슬롯 안에 콘텐츠를 유동 배치한다. 11차의 ‘PC 조립 자체에 새 결정이 필요하다’는 판단은 정정한다. 전체 시각 일치가 완료됐다는 뜻은 아니다.

## 원문과 권한: 기존 지시로 처리 가능

| 항목 | 확인한 근거 | 채택한 안전한 처리 | 현재 범위를 넘는 요구 |
|---|---|---|---|
| 출처 원문 열기 | [자산관리 원본](originals/7356929996797649648/b611bd07ed0c464581479140b9207afb.html)에 버튼이 있다. 카드가 쓰는 `api/family-portfolio.py` preview는 정규화 rows/source/fileHash/statementIdentity를 reviews에 저장(384~398행)하며, 이 경로는 업로드 원문 파일이나 열기 URL을 계좌 응답에 제공하지 않는다. | 원본 위치에 `출처 원본 (미지원)` 비활성 버튼과 미구현 설명을 유지한다. 실제 저장된 출처·기준일을 표시하며 문서가 있는 것처럼 가장하지 않는다. 사용자는 기능 없는 요소를 명확히 표시하는 방식을 이미 허용했다. | 실제 PDF/CSV 원문 열기를 추가하려면 계좌별 원문 대응·보관·접근 계약이 필요하다. 다른 수집/장부 경로의 원문 보관을 이 업로드 원문이 보관됐다는 근거로 사용하지 않는다. 이번에 구현하지 않았다. |
| 편집자 별칭 변경 | 원본 Editor 카드에도 활성 외형이 있다. 실제 `api/family-portfolio.py` edit_account(272~280행)는 쓰기 접근과 authorityUid=현재UID를 모두 요구한다. | 서버와 같은 권한이 있는 경우에만 기존 입력란으로 이동한다. 카드 버튼과 페이지의 설정 폼을 모두 같은 범위로 제한했다. 조회 전용은 비활성·폼 부재이며, 이유를 버튼 설명에 표시한다. 권한/서버 설정은 변경하지 않는다. | 모든 편집자에게 변경 권한을 주는 요구는 별도 권한 변경이다. 기존 권한 보존이라는 명시적 지시가 있으므로 이번에 묻거나 확대하지 않는다. |

## PC 원본이 이미 지정한 조립 방법

[PC Submenu Open 원본](originals/2458864221184522893/1170392357232825899.html) 56~60행은 셸 최대1280px·좌우24px·메뉴224px·간격24px이다. 133~145행은 `main.flex-1.min-w-0` 슬롯을 두고 “개별 화면 콘텐츠 … 는 이 슬롯 내부로 삽입”한다고 명시한다. 독립 blank 콘텐츠의 바깥 `main` 여백을 중첩하는 지시가 아니다. 글꼴·카드 내부 padding·간격을 축소하지 않고 원본의 유동 레이아웃을 실제 슬롯에 배치하는 것이 기존 ‘공통 셸과 콘텐츠 분리’ 지시에 부합한다.

[PC Navigation Closed 원본](originals/2458864221184522893/6fa38540cd064d57a93be9dab4eba5fb.html) 66~106행은 최대1120px·좌우16px·축소 레일56px·간격24px·나머지 본문이다. 해당 레일도 복원했다.

측정 도구: `scripts/design/measure-stitch-assembly.mjs`. 원본 HTML은 변경하지 않고 실제 CSS를 렌더링해 DOM 치수를 읽었다. `/workspace/stitch-v2-evidence/assembly-before/results.json`, `assembly-final/results.json`에 원본/구현과 출처 경로를 보존했다.

PC 본문 슬롯 폭984px는 수정 전부터 원본과 같았다. 실제 오류는 메뉴 열린 상태의 헤더/푸터를1120px로 제한한 점과 닫힌 상태56px 레일 부재였으며 둘을 수정했다. Tablet은 본문에720px 최대폭과24px padding을 동시에 적용해 안쪽이672px가 되던 오류를 수정했다. 이제768px 화면은 main768/내용720px,390px 화면은 main390/내용358px다. 모바일 원본 헤더의358px 외곽 컨테이너와 구현390px/좌우16px 컨테이너는 사용 가능한 안쪽 폭358px로 같다.

원본 셸 치수와 독립 전체 화면 PNG를 같은1280px 캔버스에서 동시에 그대로 유지하는 것을 수용 기준으로 삼지 않는다. A의 슬롯 조립과 내부 요소·상태·간격을 나눠 검증하고, 기존 전체42개 무축소 비교도 진단 증거로 계속 보존한다. 비교 영역을 숨기거나 이미지 크기를 바꿔 시각 일치를 선언하지 않는다.

## 남은 일반 작업

CURRENT_MATRIX.md의 카드 출처/유형·보유 행 표기, 관리 패널/표·프리뷰 세부 배치, 글꼴·아이콘·원본 상태 전수 대조는 일반 잔여 작업이다. 원문/권한/조립 판단을 이 외형 차이의 수정 불가 사유로 사용하지 않는다. 모든14종의 최종 시각 수용은 여전히 미완료이며 실제 계좌 검증·미생성29종·배포는 수행하지 않았다.
