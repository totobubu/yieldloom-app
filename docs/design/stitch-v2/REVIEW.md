## 비교 증거

`/workspace/stitch-v2-evidence/`에 다음 증거를 보존한다.

- `originals/`: MCP 원본 PNG 30개. 원본 HTML은 이 문서 옆 originals/에 보존한다.
- `rendered-originals/`: 18개 콘텐츠 HTML × 3개 폭 = 54장. 별도 Mobile/Tablet 원본 PNG로 표현하지 않는다.
- `shell-comparison/`: 공통 셸 12개 상태의 원본 HTML과 실제 구현 캡처·측정. 정적 자산 실패 없음.
- `content-implementation/`: 14종 × 1280/768/390px, DPR2의 실제 Vue 전체 화면과 콘텐츠 캡처. results.json에 화면별 오류·넘침·실패를 기록한다.
- `content-comparisons/`: 화면별 원본 / 구현 / 차이 3패널. PC는 다운로드 PNG, Tablet·Mobile은 원본 HTML을 해당 폭으로 재렌더링한다. 확대/축소 없이 높이 차이를 흰색으로 채운다. 채널 차이 32 초과 비율은 진단값이며 유사도·합격률이 아니다.
- 기존 `implementation/`, `comparisons/`는 초기 검색 단계 증거이며 최신 결과로 인용하지 않는다.

구현 캡처는 tests/stitch-fixtures.mjs의 고정 시각·합성 계좌·DEMO 종목을 사용한다. 개인 API는 가로채고 비GET 요청은 거절한다. 원본 금융 예시와 합성 데이터의 상충을 유지·표시하며 원본 예시를 실제 데이터에 주입하지 않는다.
