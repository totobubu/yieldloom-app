# 유사·테마 비교의 태블릿·모바일 적용

범위는 `UnderlyingExplorerView.vue`의 유사·테마 비교와 전용 표현 컴포넌트 `ResponsiveComparison.vue`다. 기준 커밋은 `28791fa`, 작업 브랜치는 `feat/stitch-comparison-responsive-20261105`다. 다른 작업자의 업로드·저장 결과·시뮬레이터 파일은 수정하지 않았다. 코드와 합성 검증을 완료했으며 **전체 픽셀 일치 수용·실데이터 검증·운영 배포는 완료하지 않았다.**

## 원본 확인

공식 Stitch MCP `https://stitch.googleapis.com/mcp`에서 `tools/list`, `tools/call`의 `get_screen`, `download_file`을 읽기 전용으로 호출했다. 기존 `STITCH_API_KEY` 런타임 바인딩을 사용했으며 키를 출력하지 않았다. 다음 네 HTML은 MCP 재다운로드 바이트와 저장소의 원본 바이트가 모두 일치한다.

| 화면      | 기기   | 공식 최종 ID                       |
| --------- | ------ | ---------------------------------- |
| 유사 비교 | Tablet | `77fdbd798a3941c68f098120a210c44d` |
| 유사 비교 | Mobile | `2476bb94e3174e6182500d8f520a6424` |
| 테마 비교 | Tablet | `12bcd42390bb468eb1700a909aec3f5d` |
| 테마 비교 | Mobile | `4dbfbf717c75483e88e6d1186ecbdb2b` |

화면 메타데이터 제목의 V10 A11Y 표기와 실제 HTML `<title>` 버전 표기는 다를 수 있다. 이것은 본문이 변경됐다는 증거가 아니다. PNG도 공식 MCP에서 내려받았으며 물리 픽셀 크기는 CSS viewport로 사용하지 않았다. SHA-256·공식 리소스 이름·실측 결과는 [검증 기록](evidence/comparison-responsive-20261105.json)에 보존했다. 원본 HTML은 변경하지 않았다.

## 구현

- 1024px 이하에서 유사·테마 화면만 전용 표현을 사용한다. 641~1024px는 가로 스크롤 지표 행 비교표, 640px 이하는 종목별 카드다. PC와 기초자산별 비교는 기존 표현을 유지한다. 미디어 쿼리 이벤트는 해제하며 viewport 변경 시 부모의 필터·자료 상태를 유지한다.
- 원본의 2열 종속 필터, 검색, 통화 표시, 테마 설명과 근거, 분석 인사이트 3개와 주의 안내, 최대 3개 비교 트레이를 구현했다. 기존 전략·방향·배당·주기 옵션과 상위 선택 시 하위 초기화를 재사용한다. 상품명 검색은 이미 받은 목록에서 수행한다.
- 기존 수익률·운용 보수·가격 하락·기간·추정 여부·공식 연결 출처는 태블릿 펼침과 모바일 종목 Dialog에 보존했다. 전체 페이지 명시 조회와 선택 트레이 조회를 제공한다. 부분 조회 후 조회하지 않은 종목을 미확인으로 바꾸지 않는다. 무배당·미확인·관측된 0을 구분하며 본주에 ETF 보수를 적용하지 않는다.
- 원본의 공유는 현재 링크와 조건을 클립보드에 복사한다. 링크가 필터를 복원한다고 안내하지 않는다. 저장은 공개 비교 조건 JSON의 로컬 다운로드이며 자동 복원은 미지원이라고 명시한다. API/DB 쓰기는 추가하지 않았다.
- 테마 원본의 USD 고정·가상 종목·가상 편입 관계를 실제 자료에 대입하지 않았다. 종목별 원문 통화를 유지하고 환산하지 않는다. 원본의 분배율·연속성 영역은 자료 미제공·산출 보류·연속성 미검증으로 남긴다.
- 원본의 Pretendard 1.3.9 변수 폰트를 OFL 라이선스와 함께 자체 호스팅하고 기존 로컬 Inter를 사용한다. 별도 `Comparison Pretendard`/`Comparison Inter` 패밀리로 등록해 PC와 다른 화면의 글꼴을 변경하지 않는다. Pretendard 파일은 약 2.06MB이며 이 표현이 사용하는 경우에만 브라우저가 읽는다.

## 후속 정밀 정렬

초기 커밋 `f064a5b` 뒤에 카드의 전체 높이를 늘리던 종목별 펼침 요약과 인라인 배당락일을 원본 카드 흐름에서 분리했다. **종목명을 누르면** PrimeVue Dialog에서 기존 분류·최근 배당·배당락일·운용보수 기준일·총수익률 기간/추정 여부·가격 하락·공식 출처와 종목 상세 링크를 확인한다. 창을 여는 것만으로 조회하지 않으며, 창의 명시 조회 버튼은 해당 종목만 조회한다. Escape 닫기·원래 제목 버튼으로 포커스 복귀를 검증했다. 필터 추가 설정과 태블릿의 전체 추가 지표 펼침은 계속 제공한다.

내부 탭의 문구와 순서는 네 원본과 일치하도록 바꿨다. 유사는 `기초지수 및 자산구성 / 유사 상품군 매트릭스 / 테마 및 섹터 분배`, 테마는 `테마 대표 종목 및 연관 ETF 매트릭스 / 기초자산 비중 및 섹터 분배 / 배당 지급 주기 및 현금흐름 대조`다. 첫 표시 상태는 원본의 매트릭스다. 비중/섹터 자료가 없는 탭에서는 명확한 미제공 안내를 표시하고 비중을 만들지 않는다. 기초자산 탭은 확인된 연결·분류를, 배당 탭은 확인된 주기·최근 배당·배당락일만 표시하며 현금흐름 예측이 아니라고 명시한다. 이 탭 전환은 추가 조회를 하지 않는다. 기존 세 비교 화면 간 링크는 `현재 조건 및 지표 조회` 안에 남아 있다.

비교 화면의 아이콘은 원본과 같은 **Material Symbols Outlined 400**의 공식 폰트로 바꿨다. 폰트와 Apache 2.0 라이선스를 함께 자체 호스팅하며 다른 화면의 PrimeIcons를 바꾸지 않는다. 후속 캡처에서 로컬 Material Symbols/Pretendard/Inter 로딩 성공, 자산 오류 0을 확인했다. 모바일 유사의 통화 배지는 파랑, 테마는 노랑으로 원본 색을 적용했다. 테마 카드의 종목 코드/상품명 크기와 본주/ETF 배지도 원본 구조를 따른다.

[최종 대조 캡처](evidence/comparison-responsive-refined/)는 저장소에 보존했다. 이전과 같은 합성 자료에서의 높이는 다음과 같다. **종목·값·문구가 다른 자료이므로 아래 수치만으로 픽셀 수용을 판정하지 않는다.**

| 상태                | 초기 앱 | 후속 앱 | 원본      |
| ------------------- | ------- | ------- | --------- |
| 유사 Mobile 카드    | 393px   | 316px   | 306.5px   |
| 테마 Mobile 첫 카드 | 365px   | 282px   | 290~294px |

원본의 예시 카드보다 실제 이름·분류·값·확인 상태가 길거나 짧을 수 있어 고정 높이로 자르지 않았다. 후속에서도 카드 폭 358px, 필터 44px, 태블릿 필터 두 열 폭, 제목 30/38·20/28·24/32px 계약은 유지한다. PC 유사·테마 및 모바일 기초자산의 변경 전후 캡처 해시는 다시 동일했다.

후속 검증은 전용 14상태(탭 미제공 의미/무조회·Dialog/초점 복귀 추가), 기존 지표 9상태, 기존 우선 패널 3폭, 변경 파일 린트·타입 검사·빌드를 통과했다. 우선 패널의 첫 병렬 실행은 다른 자산관리 화면의 `.asset-currency-summary` 대기에서 타임아웃이 났고 수정 없이 재실행한 3폭은 통과했다. 원인은 확정하지 않으며 실패 로그와 재실행 로그를 작업 환경에 보존했다.

## 남은 차이와 미검증

**전체 시각 수용은 아직 미완료다.** 치수 일부 일치와 동작 통과를 전체 픽셀 일치로 표현하지 않는다.

- 가상 종목 3개·가상 수치·공통 예시 기준일 대신 실제 목록·각 지표의 기준일·미확인 상태를 표시한다. 항목 수와 긴 이름·통화·안내 문구가 달라 전체 높이·행 높이가 원본과 같지 않다. 원본의 기준일과 검증된 실제 기준일을 임의로 맞추지 않는다.
- 기존 기능을 보존하는 필터 추가 설정과 태블릿 추가 지표 펼침, 유사 카드의 선택 체크박스가 남아 있다. Dialog는 원본에 없는 추가 상호작용이며 기본 카드 화면에는 표시되지 않는다.
- Material Symbols의 실제 글꼴을 사용하지만 PrimeVue의 기본 Select SVG 화살표, 일부 버튼·테두리·타이포그래피와 실제 문구 줄바꿈에는 차이가 남아 있다. Tablet HTML 일부의 fontFamily는 전체 문자열이 하나의 패밀리로 묶인 원본 결함이 있으며, 구현은 유효한 실제 로컬 폰트를 쓴다.
- 실제 전체 시장 자료의 완전성, 실제 개인계좌/PDF, 실기기 보조기술·브라우저 전체 조합, 운영 URL·배포는 이 범위에서 검증하지 않았다. Firebase/Firestore 실청구량도 측정하지 않았다.
- 새 전용 브라우저 검사는 로컬에서 수행했다. CI 워크플로 파일은 다른 통합 작업과의 충돌을 피하려고 수정하지 않았으며 통합자가 새 명령을 CI에 추가할 수 있다.
