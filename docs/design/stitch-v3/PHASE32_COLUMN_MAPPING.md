# 열 연결 화면 적용과 검증

현재 상태는 **코드 적용·로컬 합성 검증 통과, 전체 시각 승인 전, 운영 미배포**다. 기존 14종 전체나 새 20개 기기 시안을 완료한 것으로 세지 않는다. 구현 기준은 `main`의 `dd6d2a6d2105f5f54c3948f55a7fa3d3e8a6515f`이며, 이 시점에 이미 운영 중인 금융 데이터 변경을 보존했다. `DividendSimulatorView.vue`는 별도 담당이므로 수정하지 않았다. 이후 운영 수집 갱신 `f2dba7ecf2048bdb16bf18552e7f0cafc8d4b58a`도 병합해 BIGY/RNTY/SOXY의 검토된 월배당 출처·주기 정정을 보존했다. 공개 자료를 이번 UI에서 다시 계산하거나 덮어쓰지 않았다.

## 적용 범위

`BrokerSpreadsheetForm.vue`에 최종 열 연결 PC·Tablet·Mobile 시안의 제목, 단계 표시, 파일·계좌 영역, 인코딩·헤더 시작 행·자료 종류, 기본/상세 매핑, 통화 선택, 원본 3행 미리보기, 다음 단계 확인 영역을 적용했다. 기존 CSV/XLSX 업로드, 계좌 명의 확인, 조회일, 워크시트 선택, 프리셋 저장·삭제·복원 및 검토 이벤트를 보존했다. 기존 선택 항목 7개는 접을 수 있지만 삭제하지 않았다.

필수 항목 또는 통화 설정이 없거나 같은 원본 열이 중복 연결되면 미리보기를 비활성화한다. 저장된 설정을 복원한 경우에는 기존 계약대로 재확인해야 한다. 처리 중 PrimeVue Select도 명시적으로 비활성화했다. 서버 검증과 권한 검사는 그대로 유지한다.

`inspectSpreadsheet`의 기존 응답에 `previewRows`만 추가했다. 현재 업로드의 상위 3행, 기존 헤더 수 이내이며 원문 문자열·빈 값·0·선행 0·정밀도를 유지한다. 정규화 거래나 장부 전체를 반환하거나 저장하지 않는다. 추가 API 호출·Firestore 조회·쓰기 경로를 만들지 않았다. 기존 계좌 권한 확인 읽기는 유지한다.

Inter Latin 가변 글꼴은 OFL 라이선스와 함께 자체 호스팅한다. 실제 한국어 글꼴 대체와 아이콘 모양까지 원본과 같다고 판정하지 않았다. 다크 모드에서는 제목의 가독성을 보존한다.

## 비교 방법과 증거

최종 원본 HTML은 MCP 다운로드 해시와 일치한다. 원본 HTML 3개와 OFL 원문의 기존 줄 끝 공백은 바이트·해시 보존을 위해 유지했다. 직접 작성한 변경의 공백 검사는 통과했다. 원본 PNG도 다운로드해 리소스 이름·해시·물리 픽셀 크기를 등록했다. 원본 HTML을 수정하지 않고 같은 Chromium, 같은 viewport, DPR 2로 렌더링한 결과와 구현을 비교했다. 거래일·종목·거래 고유번호·수량·금액·통화는 고정 합성 데이터이며 실제 계좌를 사용하지 않았다.

## 수행한 검증

- `npm run lint:check`: 오류 0, 기존 경고 54. 새 컴포넌트 속성 순서 경고는 해결했다.
- `npm run build`: 타입 검사·Vite 빌드 통과. 기존 큰 청크 경고는 남는다.
- `node --test tests/*.test.mjs`: 814/814 통과.
- 포트폴리오 API 6개 스위트: 63/63 통과. 권한·가져오기·CSV/XLSX·원문 미리보기 제한·쓰기 없음 포함.
- `broker-spreadsheet.browser.mjs`: 실제 합성 XLSX/CSV → 열 연결 → 검토 → 메모리 저장 → 결산 저장/조회/삭제, 4개 폭, 입력·매핑 추가 API 요청 0 통과.
- `portfolio-enhancements.browser.mjs`: 프리셋 저장·헤더 변경 감지·워크시트 복원, 정정·XIRR·로그아웃·모바일·테마 통과. 프리셋·입력·로컬 계산 추가 API 요청 0.
- `asset-management.browser.mjs`: 합성 PDF를 사용한 등록·검토 흐름 통과. 실제 계좌/PDF가 아니다.
- `capture-broker-mapping.mjs`: 원본/구현 4개 폭, 필수 누락/완료/중복/처리 중 상태, 요청 1회만 사용, 가로 넘침 없음, 다크 모드 제목 대비 회귀 확인.

실제 사용자 로그인·실계좌 업로드·실제 PDF·운영 저장은 수행하지 않았다. 위 로컬 검증은 원격 CI, Preview 또는 Production 검증을 대신하지 않는다. 실제 운영 데이터와 보안·권한 설정은 변경하지 않았다.

재현 명령(로컬 Vite 필요):

```bash
UI_BASE_URL=http://127.0.0.1:5188 \
STITCH_CAPTURE_DIR=/tmp/yieldloom-column-mapping-review \
CHROMIUM_PATH=/usr/bin/chromium \
node scripts/design/capture-broker-mapping.mjs
```

캡처 스크립트는 localhost만 허용하고 합성 API 응답을 가로채며 임시 HTML을 종료 시 삭제한다. 최종 원본 20개 모두의 적용 현황은 [대조표](README.md)에 별도로 남겼다. 현재 구현한 열 연결 외의 17개 기기 대상은 이 커밋에서 적용·승인하지 않았다.
