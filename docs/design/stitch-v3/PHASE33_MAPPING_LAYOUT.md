# 열 연결 레이아웃 후속 검증

기준은 PR #247을 병합한 `work`의 `c48d049`이다. 이 기록의 범위는 **열 연결 화면의 주요 치수·반응형 배치와 기존 기능 보존**이다. 원본과 화면 전체가 픽셀 단위로 완전히 같다는 판정은 하지 않는다. 운영 반영 결과는 이 변경 PR의 실제 CI·배포 SHA·응답으로 별도 확인한다.

## 수정

- 파일 설정 카드에서 기존 업로드·조회일·워크시트·프리셋 삭제를 별도 펼침 영역으로 옮겼다. 파일 아이콘 버튼으로 그 영역을 열고 포커스를 이동할 수 있다. 모든 입력은 기존 `form`과 비활성화 `fieldset` 안에 유지한다.
- 인코딩·헤더 시작 행·자료 종류·CSV 안내의 기기별 배치와 행간을 원본대로 맞췄다. 제목·문맥 배지·단계 구분선·필드 상태 아이콘을 복원했다.
- PC 매핑은 원본의 12열 중 7/5열 배치와 가로 매핑 행, Tablet은 구분선 행, Mobile은 세로 카드로 조립한다. 선택 항목 7개도 삭제하지 않고 펼침 상태에서 원본의 두 열/한 열 배치·글자를 대조했다.
- 열 연결 중에만 실제 업로드 Dialog가 최대 1280px를 사용한다. 콘텐츠 패딩은 PC/Tablet 24px, Mobile 16px로 원본 프레임과 맞춘다. 표준 파일·수기 입력·검토·결과 화면의 기존 Dialog 폭은 유지한다.
- 실제 표시되는 PrimeVue 선택 값의 글자도 대조했다. 이전에는 루트의 글자만 측정해 내부 라벨 15px를 놓쳤다. 현재 기본 필드는 원본대로 PC 12px, Tablet 14px, Mobile 13px이고 추가 선택 항목은 12px다.
- 미리보기 하단에는 선택한 날짜·금액·통화 열의 **원문 인용·미확정·세전/세후 미판정**을 표시한다. 원문의 빈 값·0·소수 정밀도를 유지하며 원본의 가상 ‘세전 배당 총액’ 해설을 실제 금융값으로 사용하지 않는다. 추가 조회·저장·금융 계산은 없다.

## 치수와 증거

같은 Chromium, DPR 2, 같은 합성 CSV와 최종 원본 HTML로 비교했다. 원본 HTML 파일은 변경하지 않았다. 원본/구현 자산 다운로드 실패는 0건이다. 비교 스크립트는 실제 선택 값의 글자, 제목 영역·파일 카드의 폭/높이를 0.1px 이내로 검증하고, 필수 누락·완료·중복·처리 중 상태 및 선택 항목 7개 펼침을 확인한다.

## 검증 경계와 남은 차이

기존 거래·금액·통화·권한·저장 로직은 변경하지 않았다. API 변경도 없다. 실제 계좌/PDF·운영 저장은 시험하지 않았으며 합성 계정과 메모리 API를 사용했다. 시각 검증과 실제 로그인 검증은 별개다.

매핑 본문 카드 높이는 고정 데이터에서 원본/구현 PC 935.5/948.19px, Tablet 768 1027/1031.19px, Tablet 834 1009/1013.19px, Mobile 1132/1117.69px다. 실제 열 이름·값과 보존한 안내·확인 동작이 시안의 가상 문구와 다르다. 경고 문구는 저장된 양식이 적용되지 않았다는 사실을 표현하며, 표준 헤더 제안까지 없앴다고 잘못 안내하지 않는다. 선택 항목·설정 열기·원문 인용은 실제 기능을 유지했다.

단계 표시 내부 폭·일부 행/확인 영역 간격, 한국어 대체 글꼴, PrimeIcons와 원본 Material Symbols의 정확한 모양 차이는 추가 시각 수정 대상으로 남는다. 기존 수동 매핑은 기존대로 미리보기를 사용할 수 있고, 불러온 프리셋은 재확인이 필요하다. 시안의 확인란 문구만을 이유로 새로운 권한·저장 승인 단계를 만들지 않았다.

나머지 17개 기기 시안은 이 변경에서 적용 완료로 취급하지 않는다. 원본의 가상 수치·소유권 검증 상태·세전/세후 설명을 실제 데이터로 대체하지 않는 원칙을 유지한다.
