# 기존 추출 응답을 재사용하는 업로드 미리보기

#253에서 표준 CSV·XLSX를 추출하면 같은 preview 응답의 상위 3행을 업로드 화면에서 먼저 보여 주고, ‘다음: 데이터 검토’로 기존 전체 검토에 진입한다. PDF의 직접 검토·명의 확인·암호 흐름은 유지한다. 추가 preview/inspect API와 금융 계산은 없다. 서버 preview는 기존처럼 검토 세션을 저장하지만 거래·잔고 원장은 최종 commit 전에 저장하지 않는다. 다음 버튼은 API 없이 같은 검토를 재사용한다. 표준 파일 선택은 다음 단계로 넘어간 뒤 비우며, 비밀번호는 기존처럼 추출 후 비운다.

자료는 기존 review ref만 사용한다. 표준 200행·PDF 10,000행 분할·2MB·20 PDF 제한을 유지한다. 파일 선택/제거·형식/종류/기준일·계좌/사용자/입력 방법 변경 및 초기화에서 관련 미리보기를 무효화한다. 늦은 추출 응답의 사용자·계좌 검사와 원래 확인 체크·편집/저장 권한·PDF 기본 암호 소유자 제한을 유지한다. 개인 자료를 localStorage 등에 저장하지 않는다.

Tablet은 표, Mobile은 3개 카드로 동일한 추출 행을 보여 준다. 제공된 securityName/rawType은 그대로 쓰고, 없으면 종목 코드/기존 거래 유형명을 쓴다. 금액은 원문 문자열의 정수부 천단위만 구분해 부호·소수 자리·끝 0을 유지한다. 0은 0, 빈 금액은 미제공, 통화 없음은 미지정이다. 세전/세후·실지급·합산액으로 재해석하지 않는다. 행수도 실제 응답 길이를 쓰며 시안의 142건을 만들지 않는다.

실제 필요한 형식·기준일 입력은 추출 전에 열린 설정 영역에 두고, 추출 후 접어 원본 구조에 맞춘다. 사용자가 다시 열어 바꾸면 기존 추출 자료는 지워진다. 닫힌 설정의 필수 입력은 native invalid 이벤트에서 다시 열어 접근할 수 있게 한다. 중복 파일 규격 안내는 합치고 파일 1개·2MB·200행·50열 등 기존 제약은 유지했다.

[최신 측정](evidence/phase41/measurements.json), [Tablet 원본](evidence/phase41/source-834.png)/[구현](evidence/phase41/implementation-834.png), [Mobile 원본 fallback](evidence/phase41/source-390.png)/[구현](evidence/phase41/implementation-390.png), [미리보기 다크](evidence/phase41/implementation-preview-dark-390.png). 고정 합성 CSV 3행에 원본의 제공된 3개 예시·유형 문구를 썼다. 파일 크기와 총행수는 실제 합성 파일 기준이며, 미제공 139행을 만들어 142건으로 표시하지 않는다. 원본/구현 헤더는 834/768에서 159.5/179px로 같고 단언한다. 전체 형상은 아직 승인하지 않았다. 형식/기준일 설정 요약·파일 도구·규격/계좌 확인·글꼴/테두리/문구·Mobile 파일 선택 상태 등에 차이가 남고, 원본 Mobile 글꼴 URL HTTP 400도 지속된다.

[검증 요약](evidence/phase41/verification.json), [새 실제 흐름](evidence/phase41/inline-browser.txt). 새 검사는 합성 CSV 6행(금액 0/빈 값/통화 없음), 기준일·파일 제거·종류 변경의 로컬 무효화, 4개 폭, 다음 진입 API 0회, 수정 후 전체 6행 commit 1회, 실제 XLSX 첫 시트만의 미리보기/다음 진입·자동 commit 없음, 잔고 자료의 미제공 금액을 확인한다. 총 5개 preview는 각각 명시적 추출 클릭이며 자동 재조회가 아니다. 첫 브라우저 시도는 진입 대기에서 실패했고, 기존 통합 인증 fixture와 달랐던 테스트 설정을 맞춰 재실행했다. 초기 실패의 상세 응답은 기록되지 않았으므로 제품 원인을 단정하지 않는다. 실제 고객 인증이나 고객 자료는 사용하지 않았다.

새 검사와 수기/broker/enhancements/전체 검토/mobile-feedback/자산관리의 7종 브라우저가 통과했다. 마지막 표시 보정 후 5폭 캡처와 새 흐름을 다시 검사했고, lint 오류 0/기존 경고 54·타입/빌드가 통과했다. 새 검사를 app-quality에 추가했다. 원격 CI는 새 head에서 별도 확인하며 초안/미배포다. 이 기능 진전을 기기별 전체 원본 일치 완료로 계산하지 않는다.
