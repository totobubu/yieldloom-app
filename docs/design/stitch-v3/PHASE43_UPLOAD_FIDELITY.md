# 업로드 파일·확인 영역 보정

최종 원본 Upload Tablet `3c2a0d37b5f54a63b3a633f01f0d2b33`, Mobile `80b06442816e4d1baebc96cb520b19d6`의 저장 HTML/PNG를 기준으로 모바일 파일 선택 영역, 선택 파일 카드, 가로 초기화·다음 버튼, 문서 암호 안내, 노란 계좌 확인 영역과 누락 통화 카드 구성을 보정했다. 실제 파일 이름·크기·행수·형식과 기존 한도 및 명의 확인을 유지한다. 모의 샘플 링크는 기존 CSV 다운로드로 표시하며 지원하지 않는 자동 불러오기를 약속하지 않는다. 단계명은 원본과 일치시키되 표준 파일은 기존 전체 검토로, 증권사 표는 기존 열 연결 경로로 진행한다.

Vue scoped CSS에서 `:global(html:not(.p-dark)) .child`가 컴파일 시 child를 제거하고 html 전역 규칙이 되는 문제를 발견했다. 업로드와 운영 저장 결과 컴포넌트의 해당 light/dark 선택자를 scoped 자식 선택자로 수정했다. 공개 검색→자산관리 진입 전후 root 색상·배경·테두리가 동일한지 실제 브라우저로 확인한다. 이전 검사는 이 비교에서 실패했고 수정 후 통과했다. 금융 로직·API·권한 변경은 없다.
