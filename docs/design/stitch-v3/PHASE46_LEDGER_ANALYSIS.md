# 장부 분석 원본 구조와 실제 원장 연결

최종 Tablet `65c1b225397746ada071cf14ae4f687c`, Mobile `986013fd6b61404f82b4eeda2b643cd6`의 HTML/PNG를 AdvancedPortfolioInsights의 기존 실제 기능과 대조했다. 헤더·최대834px·1024px부터7:5 구조·2×2 지표 카드·저장 원장 필드 표·확인 필요 행 강조·유형별 집계 카드·기존 분석 안내를 연결한 부분 구현이다. 기존 상위 분석의 계좌/통화/월 선택과 XIRR·완전 청산 조건/체크·결과를 보존한다. 별도 시뮬레이터/비교 파일은 수정하지 않았다.

추가 표는 이미 받은 저장 원장의 선택 계좌·선택월 및 날짜 미확인 행만 보여 준다. 날짜 미확인 행은 선택월 거래로 확정하지 않는다. 로컬 거래 유형 필터와100행 페이지로 전체 행에 접근한다. 저장 값을 증권사 불변 원문으로 부르지 않고 원문 대조가 필요함을 표시한다. 0은0, 빈 금액/단가는 미제공, 빈 통화는 미지정이다. 수량×금액으로 단가를 추정하지 않는다. 금액 문자열의 정수부만 천단위로 나누며 부호·소수 정밀도·끝0을 보존한다. 타 계좌 행을 추가로 읽거나 표시하지 않는다. 파일/API/Firebase/원장 쓰기·외부 수집·캐시·기존 금융 계산 변경이 없다.

배당 연속성의 정의는 원본에 없으므로 산출 보류로 명확히 표시한다. 기존 report.trend.percent는 최근3개월 대 직전3개월 배당 기록의 증감률이며 연속성 값으로 바꾸지 않는다. XIRR와 청산 손익은 기존 사용자 확인 및 자료 조건을 그대로 요구하며 계좌·종목별 결과를 유지한다. 시안의 가정 청산 손익 +40,000 KRW·표본의 정상/격리 비율·예시 외부순입금을 실제 계산 결과로 복사하지 않았다. 기존 유형별 집계는 선택 통화/nativeAmount 계약 그대로이며 다중 통화 합계나 외부 원금으로 재해석하지 않는다.

기존 portfolio-enhancements(XIRR10%와 월 변경 초기화 포함) 및 stitch-analysis-records 6개 상태가 통과했다. 최종 lint 오류0/기존경고54, 타입·빌드 통과. 새5폭 기능 검사를 CI에 추가했고 CI에서는 원본 네트워크 캡처를 생략하고 기능 검사/실패 자료를 보존한다. 로컬 원본 대조와 CI 합성 기능 검사를 구분한다. 실제 인증 계좌·고객 원문/정산 검증과 운영 배포는 미완료다.

남은 차이: 상위 분석 필터를 원본 내부 필터로 통합하는 연결, 양 통화 카드와 외부 순입금의 정확한 의미/자금 분류 계약, 원문 단가·명칭/증거 필드, 정합성 완료율의 판정, 연속성 계산 정의, 하단 캘린더/분석CSV/미식별 재연결 도구, 원본 아이콘·색·간격과 기존 상세 분석의 배치. CSV/재연결 도구를 작동한다고 표시하지 않았다. 없는 계약을 만들지 않고 미적용/미확정으로 기록한다. 적용2개나 전체 리디자인 완료로 세지 않는다.
