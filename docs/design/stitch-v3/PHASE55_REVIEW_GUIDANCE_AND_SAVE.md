# 검토 화면 안내·저장 영역 정렬

대상은 #256의 일반 거래 CSV/XLSX/증권사 매핑 검토다. 원본 final ID Tablet `5aa7a573854a46db9b106f89c09c4f23`, Mobile `6bd9777b8bea43b98aea8397a29f809a`의 보존 HTML·PNG를 사용했다. 원본 파일은 수정하지 않았다. PDF와 보유 입력의 기존 검토·동의·저장 경로는 유지한다.

보조 지표와 기존 검증 안내를 예시 안내의 펼침에 보존했다. Vue3.5의 deferred Teleport를 쓰며 비거래 검토에서는 원래 위치를 유지한다. 펼침 열기·안내 접근·닫기·잘못된 Teleport 경고 없음도 검사한다. 기본 화면에서 정보를 삭제하거나 가짜 정상 상태를 만들지 않는다. 원문 행은 API 미제공이므로 비활성 ‘원문 보기 (미지원)’와 직접 대조 안내를 유지한다.

저장 버튼과 이전 단계 버튼을 원본의 같은 동작 묶음에 배치했다. 일반 거래의 표시 문구는 ‘배당달력 포트폴리오에 저장 및 반영’이며 접근성 이름도 동일하다. 기존 handler·busy·명의·계좌·동의 차단과 원래 행 전체 검증은 유지한다. PDF/보유의 버튼 문구는 기존대로다. 원본 Material Symbols 공급자의8개 SVG를 로컬 자산으로 사용하며 URL·SHA는 증거에 있다. 외부 런타임 글꼴 요청은 추가하지 않는다.

## 검증과 한계

5폭 캡처·가로 넘침0·API0·키보드 편집 열기/닫기/재열기·원래 행 번호·필터 상태에서 전체 행 저장·동의 취소·busy/차단·0/누락/소수/통화·보조 안내 펼침 검사가 통과했다. Memory API의 CSV/XLSX 101행 편집·저장, 수동 보유,5초 지연 증권사 분석,4716행/24배치 PDF 합성 저장, 모바일 오류/재시도, 기존4개 SFC dark 격리를 통과했다. 변경한 테스트는 일반 거래 버튼의 실제 문구만 갱신했으며 금액·명의·저장 단언을 완화하지 않았다. 린트 오류0/기존경고54다. 빌드·원격 CI·미리보기의 최종 결과는 각 실제 실행 증거로 별도 기록한다.

전체 시각 수용은 보류한다. phase54의 원본 PNG와 원본 HTML 재렌더링 자체 차이가 지속된다. 원본 HTML의 전체 fontFamily 목록 인용과 Tablet 폰트 요청 실패는 확인했지만 실제 PNG 글꼴은 확정하지 못했다. 대체 글꼴 실험으로도 완전히 일치하지 않아 임의 폰트를 채택하지 않았다. 실제 로그인 계좌·고객 PDF 종단 검증과 원문 보기 구현은 완료하지 않았다. 현재 운영 버전은 main90f0673이며 이 기록 자체는 운영 반영 증거가 아니다.
