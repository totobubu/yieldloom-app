# 비교 필터 화살표 원본 보정

#258의 `ResponsiveComparison.vue`만 수정했다. 별도 소유 `UnderlyingExplorerView.vue`는 변경하지 않았다. 유사·테마 최종4개 원본 HTML은 필터에18px Material Symbols `keyboard_arrow_down`을 사용한다. 기존 PrimeVue Select의 기본 SVG 화살표 대신 공개 `dropdownicon` 슬롯에서 이미 자체 호스팅 중인 같은 Material Symbols 글꼴을 사용한다. 목록·값·종속 필터·키보드·조회 경로는 변경하지 않았다.

유사/테마834·390px의 실제 원본·구현을 다시 캡처했다. 전후 모든 기록된 프레임·필터·카드·표 치수는 같고 원본/구현 자산 실패·HTTP 오류는0이다. 새14개 viewport/view 기능 검사는 통과했다. 변경 파일 린트 오류0이다. 전체 비교 지표·시각 수용·운영 배포와 실제 자료 검증을 이 작은 보정으로 완료 처리하지 않는다. 기본 필터의 실제값/보조 기능/예시 자료 차이와 원본의 잘못 인용된 fontFamily는 기존 기록대로 남는다. 빌드·최종 원격 검증은 실제 완료 결과를 별도 기록한다.
