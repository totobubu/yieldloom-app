## 구조와 글꼴

갱신 안내의 재시도 버튼을 텍스트 옆 열에서 원본의 전체 폭 행으로 옮겼다. 안내 제목·본문의 크기/행간과12px 그룹 간격을 원본으로 맞췄다. 실패/갱신 중 문구를 실제 accountsState로 구분하며, 서버 DB 상태를 직접 확인했다거나 원본 예시5건을 저장했다고 고정 표시하지 않는다.

태블릿 저장 결과의 원본에는 정상 Pretendard CDN CSS가 있다. 같은768px의 로컬 고정 fixture에서 구현은 선언만 된 Pretendard 대신 시스템 Noto Sans CJK KR로 대체됐고, 원본은 실제 custom Pretendard를 사용했다. 이 fixture는 index.html의 Google Fonts 링크를 포함하지 않으므로 실제 로그인 운영 화면의 사용 글꼴을 직접 검사했다는 뜻이 아니다. 같은 문구/폭/12px/19.5px에서도 줄수가 달랐다. 원본 CSS가 지정한 Regular400·Bold700 WOFF2를 바이트 변경 없이 저장했고 원본 URL·SHA256·SIL OFL1.1 라이선스를 함께 보존했다. 별도 CSS family alias를 만들어641px 이상 갱신 안내 문단에만 사용한다. 전역 Pretendard 정의를 등록해 다른 화면의 글꼴을 바꾸지 않는다.

실제 브라우저 CDP에서 구현과 태블릿 원본의 사용 글꼴이 custom Pretendard임을 확인했다.834/768px은 로컬 글꼴2개가 로드되고390px은0개다. 이는 해당 HTML 원본/자산에 관한 확인이며 native PNG의 모든 글꼴이나 Mobile의 잘못된 family 선언까지 일치한다는 뜻이 아니다. 기존 검토/업로드 원본의 잘못된 Google Fonts 요청과 이 정상 CDN 원본을 구분한다.

후속 작업은 원본의 잠금 상태 표시·달력/조회 버튼·CSV·추가 등록 그룹 순서로 맞췄다. Mobile에서 CSV는 잠금 안내 앞, 추가 등록은 구분선 뒤에 놓인다. 실제 CSV는 선택 계좌 전체 내역이므로 별도 문구를 숨기는 대신 버튼을 ‘선택 계좌 전체 내역 CSV로 내려받기’로 표시했다. 영수증 행만 내보내는 것처럼 변경하지 않는다. 날짜·금액·완전성·집계 계약은 그대로다. Mobile 상세 행의 금액 행간20px과 중복 행 테두리2px도 실제 원본 CSS에 맞췄다.
