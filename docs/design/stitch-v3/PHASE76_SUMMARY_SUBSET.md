# 요약 화면의 복수 계좌 부분 선택

원본 `7356929996797649648/008f9456b8c643d0b9f41957447b9afc`의 계좌별 체크박스·전체 선택·초기화를 기존 요약 집계에 연결했다. 기존 구현은 전체 또는 한 계좌만 선택할 수 있었다. 공식 Stitch MCP에서 현재 HTML·PNG를 다시 읽었고, HTML은 보관 검토본과 같은 바이트다. [원본 무결성](evidence/phase76-summary/fresh-source-integrity.json).

선택은 요약 화면의 로컬 상태다. null은 현재 허용 계좌 전체, 빈 배열은 명시적인 미선택이며 선택 집합은 현재 서버가 반환한 허용 계좌와 교집합으로 제한한다. 선택한 계좌가 삭제되거나 허용 목록에서 빠지면 전체로 확대하지 않고 미선택을 유지한다. 세션 사용자 변경은 기본 전체로 초기화한다.

기존 summarizeSelection 배열 집계를 그대로 재사용한다. 전역 편집 계좌·다른 탭·금융 계산·서버 권한·API·캐시는 바꾸지 않는다. 평가 컴포넌트에는 nullable 배열 scope prop을 더해 기존 단일 prop 소비자를 보존하고 표시·페이지 리셋만 바꾼다. 기존 전체 positions·quote watch 입력은 유지한다. 미선택 안내와 v-show로 기존 평가를 숨겨 재선택 시 remount와 추가 조회를 막는다.

기존 요약 회귀 두 파일을 확장했다.1280/768/390에서 전체·단일·3개 중2개·미선택·복원, 통화별 분리, 시세 미확인, 삭제/권한 목록 축소 후0/2 선택 유지, viewer snapshot 미확인, Escape와 포커스 복귀를 통과했다. 선택 조작의 추가 API 요청은0건이고 URL·localStorage·sessionStorage도 바뀌지 않았다.12행 명세의2페이지→미선택→복원은1페이지로 돌아오며 추가 읽기가 없다. 기존 금융 assertions를 유지했고 별도 CI 파일이나 운영 쓰기를 추가하지 않았다.

부모 통합 트리는 인계 커밋 a52ee8ca65ffe1937ec4d1c3ec57a3975cb0eb73과 파일 내용이 같음을 확인했다. [회귀 인계](evidence/phase76-summary/agent-report.md), 같은 폴더의 실행 로그·3기기 전후/다크/원본 HTML 재렌더 PNG를 참조한다. 부모 통합의 타입 검사 포함 전체 빌드와 수정 파일 lint도 통과했다. 원격 CI와 운영 반영 여부는 별도 검증한다.
