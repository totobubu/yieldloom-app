## 권위 있는 원본과 측정

MCP `get_screen`·`download_file`로 프로젝트7356929996797649648의 `bd619d24ceb74c92afad1787a364ab4b` HTML과 native PNG를 새로 읽었다. 둘 다 기존 mapping 해시와 같으며 native PNG를 직접 확인했다. [무결성](evidence/phase78/fresh-reference-integrity.json). 원본 HTML/금융 예시는 수정하지 않았다.

고정 합성 데이터를 사용한 앱과 변경하지 않은 원본 HTML을 1280·834·768·390px, DPR2에서 대조했다. [수정 전](evidence/phase78/before/geometry.json), [수정 후](evidence/phase78/after/geometry.json), [재현 스크립트](../../../scripts/design/measure-dividend-trend.mjs).

| 대응 속성 | 수정 전 | 수정 후 / 원본 HTML |
| --- | --- | --- |
|제목 글자/줄높이/굵기|22.5/31.5px,700|20/28px,600|
|범례 사각형|8×8px|12×12px|
|막대가 차지하는 세로 영역|174px|144px|
|차트 배경/격자|없음|24/96/160px 위치의 3선·12px 모서리·224px 높이|
|차트 폭 PC/834/768/Mobile|다른 구조|1168/738/672/620px, 네 폭 모두 원본과 같음|
|카드 패딩|PC20/Tablet20·16/Mobile16px|24px,768px 미만20px|
|연도 버튼 실제 높이|전역 최소44px에 영향받음|32px, 원본과 같음|

원본 `font-label-sm`은 가족 선언만 있는 클래스여서 실제 렌더된 범례/연도/단위는16px/24px다. 토큰 이름만 보고11px로 추정하지 않고 실제 스타일을 측정해 맞췄다. 사용한 글꼴 선언과 원본 PNG 전체의 실제 폰트 동일성은 별개로 미수용이다.

제목 표식, 범례+연도 그룹, 단위/주의문, 14px 막대·6px 간격, 당월 부분 점선/반투명, 부분/미확인 월 표시를 원본에 맞췄다. 차트는 내부에서 가로 스크롤하며 키보드로 마지막 월에 진입하면 그 월이 보인다. 기존24개월은1232px 내부 플롯으로 유지했다. 현재 월에 실제 관측 금액이 없으면 ‘부분’ 대신 ‘미확인’이며, 빈 이전 연도도0으로 채우지 않는다.

## 보존한 기능과 검증

집계·기간·미확인·전년 비교를 만드는 `<script setup>` 바이트는 변경 전과 동일하다. [스크립트 해시와 경계](evidence/phase78/scope.json). 서비스·API·캐시·금융 계산·권한·의존성·보안 설정은 바꾸지 않았다. 연도/12·24개월/ROC 전환은 기존 응답을 재사용하며 추가 API 읽기0이다. 운영 DB 읽기·실제 청구량은 측정하지 않았다.

- 타입 검사 포함 build 성공, 전체 lint 오류0·기존 경고54, Node819/819 성공.
- 배당 탐색3폭+당월 미관측/빈 이전 연도, 지표/공시·추정·미확인15상태, 분할 비교20상태, 종목 상세 및 security-insights4폭을 통과했다. 금융 값·ROC 미확인·단일 공개 읽기·기존 키보드/모달 복귀 기대값을 유지했다.
- 해당 새 월 상태 검사는 기존 CI의 배당 탐색 스위트에 포함된다. 원격 CI·Preview·운영은 로컬 통과와 분리해 후속 운영 기록에 남긴다.

## 남은 시각 차이와 안전 경계

기존 도움말 버튼, 최근12/24개월 도구, 선택 월 상세는 원본 정적 프레임에 없지만 실제 기능이므로 유지했다. 따라서 이 추가 영역의 높이와 실제 데이터 막대 높이·문구·전체 화면/폰트/native PNG 수용은 완료가 아니다. 숫자·해석을 원본 가상 데이터로 바꾸거나 빈 공간으로 전체 높이를 맞추지 않았다. 실제 인증 계좌·고객 PDF·운영 쓰기 종단 검증은 미수행이며 시뮬레이터 공개 PR 승인 차단을 유지한다.
