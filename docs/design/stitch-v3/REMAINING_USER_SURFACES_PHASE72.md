## 최종20개 기기 시안과 기존 화면 중복

열 연결3, 업로드2, 저장 결과2, 검토2, 유사2, 테마2, 장부 분석2는 운영 연결15개다. 유사·테마는 위 기존 화면과 중복이다. 시뮬레이터2·세율 비교3은 별도 인계/승인 대상5개이며 운영 연결/완료로 올리지 않는다. 시뮬레이터 공개PR 생성에 대한 기존 거절은 유지하고 새 PR이나 우회 경로를 만들지 않는다.

장부 분석은 내부 필터·원문 필드·미지원 지표·보조 도구 및 실제 계좌 상태 대조가 남는다. 업로드/열 연결/검토/저장 결과는 실제 입력→검증→저장의 독립 상태이므로 하나가 보정됐다고 나머지를 완료로 표시하지 않는다.

## 이번 UI 수정으로 채울 수 없는 기능

- 행별 파일 원문 보기/원본 파일 열기: GenericImportReviewTable·PortfolioImportReview·AssetAccountList에서 미지원 명시. 저장 자료/권한 계약이 선행되어야 한다.
- 요약의 별도 자료 검토 상세 화면과 배당 성장률: 현재 비활성/준비 중으로 실제 코드에 명시. 새 원본/기능 계약 없이 더미 클릭 성공을 만들지 않는다.
- XLSX 내보내기·암호화 표준 XLSX 암호 입력·조건 JSON 자동 불러오기: 기존 CSV/입력/저장 동작을 보존하고 지원 범위를 명시한다.
- peer TTM/세전YOC/지수 정의, 미제공 비중/섹터/원화 환산/금융 집계: 실제 원본과 정의 없이 예시 숫자/0으로 채우지 않는다.
- 실제 고객 OAuth/증권사 자동 동기화·실제 세무 판정은 시안 적용 범위를 넘는 별도 공급자/권한/데이터 기능이다.

실제 인증 계좌·고객PDF·운영 DB 쓰기 종단 검증은 미수행이다. 합성 파일/loopback Memory API·익명 공개 화면·정적 운영 자산 확인과 구분한다. HTML 재렌더 치수/선택 글꼴 확인을 native PNG 완전 일치로 판정하지 않는다. 이번 단위의 결과와 최종 배포 SHA·CI는 검증 후 별도 기록한다.


후속 운영 확인: [phase73](PHASE73_USER_SURFACE_PRODUCTION.md). 5개 개선은7b8f4ba에 반영됐으며 위 계약/원본/실계좌 검증 잔여는 계속 남는다.


## 후속 phase74 — 로컬 통합 검증, 운영 반영 전

- 시세 이력: PC46px 행,1024포함 카드 전환,834/768/390카드261.5px·세부행32.5px와17px 제목/미수집 안내를 보정했다. [원본과전후근거](PHASE74_PRICE_RECORDS.md). 금융표기·글꼴·native 전체 수용 잔여는 그대로다.
- 종목 기본의 익명 의견: 전송 중 새 입력이 성공 응답으로 지워질 가능성을 기존 busy 상태로 방지하는 로컬·통합3폭검사를통과했다. 실제 의견POST나계좌쓰기 검증은 하지 않는다.
