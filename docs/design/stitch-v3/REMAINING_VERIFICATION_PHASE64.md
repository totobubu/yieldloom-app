# 운영 연결 화면 잔여 작업과 검증 경계

2026-11-05. 이번 조사의 코드 기준은 PR #267의 1c5c97c이며 실제 운영 기준은 아래 배포 증거에 따로 기록한다. 기존 14종과 최종 20개 기기 시안은 중복되므로 합산하지 않는다. 최종 20개 중 운영 연결 15개, 외부 인계/승인 대기 5개다. 운영 연결 수를 전체 시각 완료율로 사용하지 않는다.

최종 선택20개 ID를 사용자 인계와 다시 대조했고, 각 HTML20개와 PNG20개의 실제 바이트·SHA256 및 연결 컴포넌트 존재를 모두 확인했다. 이는 참조 무결성 확인이며 전체 시각 수용은 아니다. 상세는 [원본 무결성 기록](evidence/phase64/reference-integrity.json)에 기록한다.

## 이번에 재현·수정한 장애

Pages 비교 직접주소는 compare 진입 파일 부재로 HTTP404였다. 배포 시 같은 index에서 compare.html을 생성한다. 아이콘 글꼴 로드 전 195.5625px 문자열이 834px 화면의 문서폭을868px로 넓히던 현상은 원본18px 아이콘 상자만 제한해 고쳤다. 수정 전 두 회귀 검사는 실패하고 수정 후 통과했다. 실제 운영 주소·새로고침·전환 프레임 결과는 별도 배포 기록에 연결한다. 금융 값이나 표의 overflow를 숨겨 맞추지 않았다.

기존14종의 검색·상세·시세·배당·공유·기초자산 비교·요약·보유·달력·분석·자산관리·계좌등록 등에는 전체 프레임 시각 수용이 남는다. v2 SCREEN_STATUS의 과거 ‘운영 미반영/미생성29’ 문구는 당시 기록이며 현재 배포 상태를 대신하지 않는다. 최신 운영은 v3 CURRENT_ROLLOUT와 배포 증거를 따른다. 기존 참조의 일반 UI 차이를 데이터/권한 문제로 돌려 완료 처리하지 않는다.

실제 운영의 추가 발견: 두 주소의 유사/테마 document.title은 `- 모으멍 배당달력`이며 화면 h1은 `종목 비교`다. App.vue의 titleTemplate은 있고 UnderlyingExplorerView에는 useHead 제목이 없다. 직접주소/전환 수정과는 별개인 문서 제목 누락으로 후속 수정 대상이다. 별도 담당 파일 동시수정 금지 지침을 지켜 해당 페이지를 변경하지 않았다. 후속 담당자는 기존 `section` computed와 `comparisonSections`의 제목을 사용해 페이지별 useHead를 연결하고 직접 진입·view 쿼리 전환·검색으로 복귀할 때의 title을 검사할 수 있다. 전역 titleTemplate이나 금융 조회를 바꿀 필요는 없다.

## 별도로 막힌 범위

- 원본 PNG와 원본 HTML 재렌더링의 글꼴 자체가 다르다. HTML fontFamily 전체 목록의 잘못된 인용과 Tablet 글꼴 요청400은 확인했지만 PNG의 정확한 글꼴은 확정하지 못했다. 임의 패딩·대체 폰트로 전체 일치를 주장하지 않는다.
- 가격 달력/일자 상세 및 ROC 상세 등은 진입 지시만 있고 다운로드한 원본에 해당 상세 프레임이 없어 원본 제공 전까지 픽셀 수용을 판정하지 않는다. 기존 기능은 보존한다.
- peer 세전 TTM·현재 세전 TTM 기반 과거 매수가 YOC·지수/추적 지표는 기존 지표와 의미가 다르다. 자료·기간·통화·기업행사·완전성 및 지표 정의가 확보돼야 새 지표를 추가할 수 있다. 기존 수치를 새 이름으로 바꾸지 않는다. 최근1건과 별도12개월 카드는 사용자 선택대로 유지한다.
- 실제 로그인 계좌와 고객 PDF의 업로드→매핑→편집→동의→저장→원장/결과 확인은 별도 실제 흐름 검증이 남는다. 이번 익명 공개 검사 및 합성 Memory API 검사를 이 항목의 완료로 표시하지 않는다. 사용자 자료를 변경하는 검사를 임의로 실행하지 않는다.

우선순위는 이번 두 운영 장애의 실제 해소 확인, 공개 화면의 실행/반응형 회귀, 참조가 있는 화면의 상태별 UI 차이 재측정 순이다. 새로운 지표·권한·원본 없는 팝업을 만들어 완료 수를 늘리지 않는다.
