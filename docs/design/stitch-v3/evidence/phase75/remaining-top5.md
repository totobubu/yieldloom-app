# Phase75: 기존 14종의 영향 큰 잔여 5개 — 읽기 전용

기준: 동결된 로컬 Git 객체 `b708e33`(#277 계열). 보존 Stitch HTML과 같은 커밋의 실제 코드를 대조했다. 새 브라우저/원격 조회, 소스·문서 수정, 계좌/PDF 접근은 수행하지 않았다. 아래는 화면 전체 미구현 개수가 아니라 서로 다른 잔여 작업 5개다. 옛 `0/14`/`29 미생성` 수치를 현재 운영 집계에 사용하면 안 된다. 기존14종과 신규20개 기기 시안은 겹치므로 합산하지 않는다.

## 1. 요약: 복수 계좌의 일부 선택이 불가능 — 기능 연결

- 원본 `008f9456b8c643d0b9f41957447b9afc` HTML37–54: `전체선택`과 계좌별 체크박스. 임의의 일부 계좌를 함께 선택하는 구조다.
- 현재 `src/pages/FamilyPortfolioView.vue:491`, `:554–564`, `:1449–1453`: `summaryAccountId` 문자열과 단일 select. 전체 또는 한 계좌만 가능하다. `summarizeSelection`(:494 이후)은 이미 선택 계좌 배열을 처리한다.
- 정확한 막힘: 새로운 데이터나 권한 부재가 아니라 **복수 선택 상태와 기존 집계의 연결 누락**. 현재 권한으로 표시된 계좌 범위를 넘어서는 접근은 필요 없다.
- 최소 후속: 표시된 허용 계좌의 선택 집합을 기존 집계로 연결. 3개 중 2개/전체/삭제된 선택/빈 선택, 통화 분리, 미확인 스냅샷 보존 검사. 원본 체크박스의 기기별 배치 확인. 이 5개 중 가장 독립적으로 구현 가능한 후보다.

## 2. 요약: 별도 자료 검토 상세 진입은 비활성 — 목적 화면 계약/참조 부족

- 같은 원본 `008f9456b8c643d0b9f41957447b9afc` HTML454: `자료 검토 상세 진입`.
- 현재 `src/components/portfolio/PortfolioValuation.vue:460–468`: 같은 버튼이 `disabled`; “별도 검토 화면 미구현 · 위 평가 명세에서 자료별 사유를 확인” 표시.
- 정확한 막힘: **별도 목적 화면/상태가 미구현**. 기존 평가 명세와 사유 조회 전체가 없는 것은 아니다. 보존 자료에서 이 진입 후의 독립 상세 프레임은 확인되지 않았다(전체 Stitch 서버에 없다는 판정은 아님).
- 최소 후속: 기존 명세로 이동하는 진입으로 채택할지, 별도 상세 프레임/경로를 제공할지 결정 후 연결. 근거 없이 비어 있는 모달을 만들어 버튼만 활성화하지 않는다.

## 3. 자산관리: 출처 원본 열기 불가 — 자료 참조와 권한 있는 연결 경로

- 원본 `b611bd07ed0c464581479140b9207afb` HTML142/190/238: 계좌별 `출처 원본`; HTML397–414: 원본·증빙 목록 및 다운로드.
- 현재 `src/components/portfolio/AssetAccountList.vue:103–109`: `출처 원본 (미지원)` disabled, 저장된 출처·기준일만 안내. 별칭 수정(:84–102)은 이미 권한 가드와 실제 이동 핸들러가 있으므로 누락으로 세지 않았다.
- 정확한 막힘: **이 계좌/출처 카드에서 실제 보관 파일 참조를 권한 있는 읽기 경로로 연결하는 기능 미지원**. 별도 private statements API 존재와는 구분한다. 서버 전체에 원문 저장/조회가 없다고 단정하지 않는다.
- 최소 후속: 계좌의 출처→보관 파일 식별자와 기존 읽기 권한 계약을 먼저 확인하고 연결. 파일 없음/권한 없음/삭제됨을 각각 처리. 실제 계좌나 고객 PDF를 열어 확인하는 작업은 이번 범위에서 하지 않는다.

## 4. 공유: 피어 TTM 및 세전 YOC는 기존 카드와 다른 지표 — 정의/데이터 계약
