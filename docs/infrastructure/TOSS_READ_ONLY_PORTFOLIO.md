# 토스 읽기 전용 연결의 상태와 기준 문서

과거 이 문서의 Client Credentials 토큰·계좌·보유수량 API 흐름은 공식 사양과 실제
계좌로 검증된 운영 절차가 아니다. `TOSS_CLIENT_ID`·`TOSS_CLIENT_SECRET` 설정이나
서버 IP 허용만으로 사용자 계좌 연동이 완료된다고 해석하지 않는다.
현재 API 검토와 비활성 상태는 [토스 연동 검토](../integrations/toss-portfolio.md)를 따른다.
이 문서는 새 자격 증명·권한·서버 IP 설정을 지시하지 않는다.

관리자 시트 장부의 최신 데이터 가져오기는 같은 컴퓨터의 기존 토스 로그인 창을 사용하는
읽기 전용 브라우저 수집 경로다. 해당 결정과 원문·승인값·시각·자금 구분은
[시험 장부 기준](../SHEET_TRIAL_LEDGER.md#장부-해석과-브라우저-수집의-불변-조건),
저장·영수증·중복 방지·재개는 [관측 배치 계약](../SHEET_OBSERVATION_BATCHES.md)을 따른다.
UI·배치 API 준비를 실제 브라우저 어댑터·계좌 연결 완료로 표현하지 않는다.

브라우저 수집을 미검증 Open API로 대체하지 않는다. 쿠키·세션·비밀번호를 클라우드로
전송하거나 새 영구 권한을 임의로 설정하지 않는다. 주문·환전·출금 등 금융 동작은 금지한다.
