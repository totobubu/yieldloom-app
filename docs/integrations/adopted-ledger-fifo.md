# 채택 장부 FIFO 자산 리포트

## 범위와 단계

PR #203 head 17f25f7을 기반으로 별도 로컬 브랜치에서 구현한다. 원문·채택 장부를
다시 비교하거나 바꾸지 않고 기존 private report reader의 검증된 투영을 입력으로 쓴다.
중단된 PDF replacement 파일은 이 checkout에 없으며 교체·이관 API를 호출하지 않는다.
커밋은 (1) 정확한 계산과 정책 (2) 인증된 입력/보정 저장 (3) 화면과 회귀 검증으로 나눈다.
실제 금융 API·R2 쓰기·운영 보정 저장·새 인증·push·게시·배포는 수행하지 않는다.

## 확정 정책 (사용자 2026-11-01)

1. 잔여 FIFO 취득원가와 누적 매수금액(매수 수수료 포함)을 별도 표시한다.
2. DRIP는 취득원가/누적 매수에 포함하지만 외부 투입금에는 더하지 않는다. 출처를
   확인하지 못한 매수는 외부 원금이나 배당 재투자로 임의 배정하지 않는다.
3. FIFO 매도손익과 현금 인출은 별개다. 외부 순투입금=외부 입금−외부 인출이다.
4. 과거 원가 미상은 null이다. 기초 lot의 원래 취득일·수량·통화·근거와 수기 원가를
   보존하고, 기초 원가 입력은 외부 입금으로 취급하지 않는다.
5. 정산액이 있으면 이중 수수료를 차감하지 않는다. 없으면 매수 금액+수수료+세금,
   매도 금액−수수료−세금이다. 비용 미상은 원가/손익 미상으로 유지한다.
   USD 손익과 거래별 KRW 환산 손익은 분리한다. 실제 KRW 원가/수취액 수기 보정은
   별도 레이어이며 미상 환율을 추정하지 않는다. 알려진 기록 환율은 기준을 표시한다.
6. 확인된 가족 이동만 가족 전체의 외부 입출금에서 제외한다. 미분류 현금은 미상이다.
7. 동일 소유자의 증권 계좌 간 주식 이동만 원 취득일/원가를 승계한다. 소유자가 다른
   주식 이동은 증여 원가를 추정하지 않고 보류한다. 이전 입고 이력 부재는 원가 미상이다.
8. 근거가 확인된 분할/병합은 총 원가를 보존하고 수량만 비율 조정한다. 단주 현금은
   별도 실제 처분 수량/수취액으로 입력한다. 시세 분할 자료를 자동 적용하지 않는다.
9. 배당 회수율=누적 세후 배당÷누적 외부 입금. DRIP·기초 원가는 분모에서 제외한다.
   분모 0/미상 또는 세후 배당 미상은 비율 null과 이유를 반환한다.

## 계산 계약

원문 소수 문자열은 BigInt 유리수로 계산한다. 중간 반올림 없이 lot를 나누며 출력에서만
유한 소수는 정확히 출력하고 순환 소수만 18자리 반올림을 명시한다. 서로 다른 통화/계좌 lot는 섞지 않는다.
동일 계좌의 동일 사건은 한 번만 처리하고 충돌은 계산을 보류한다. 미체결·취소 원문과
중복 미확정 관측은 입력에서 제외한다. 부분체결 취소의 체결 수량은 유지한다.

실제 단일 체결 시각 근거가 있으면 시간순으로 처리한다. 일자만 있는 자료는 같은
계좌/종목/일자의 복수 사건에서 순서를 추정하지 않는다. 주문 누적 체결의 마지막 시각은
개별 체결 시각으로 승격하지 않는다. 단일 체결 확인 보정은 근거와 함께 별도 저장한다.
과거 수량 부족, 시각 충돌, 원가/비용 미상은 해당 종목의 확정 원가/손익을 보류한다.

기존 wife 기준과 새 profile의 계좌 바인딩이 다른 경우를 자동 연결하지 않는다.
같은 명의의 다른 계좌도 명시적으로 확인한 이전 기록이 있어야 lot를 이동한다.

## 저장·조회·화면

기존 sheet-reports의 assets 구분에서 같은 UID/workbook 권한을 확인하고 snapshot을
한 번 읽는다. 기본 거래 목록의 조회/Firestore 읽기 수는 유지한다. 새 리포트만
fifo 보정 상태 문서 1개를 추가 읽으며 계좌 필터 변경은 메모리에서 계산한다.
상태 경로는 sheetTrialLedgers/{uid}/fifoAdjustments/state이고 원문/채택값과 분리한다.
revision·ledgerRevision·requestId를 검증하는 트랜잭션으로 추가/되돌리기를 기록한다.
같은 요청 재시도는 쓰기 없이 재사용하고 충돌·다른 UID·다른 장부 버전은 거절한다.
보정은 최대 300개 이력/500KB로 제한하며 잘라내거나 덮어쓰지 않는다.

/admin/sheet-ledger?view=assets에서 공통 계산 결과와 수기 보정/이력/되돌리기를 제공한다.
기존 포트폴리오의 PDF 파생 추정값을 이 리포트에 자동 병합하지 않는다.
가격은 기존 공용 시세 서비스를 재사용하고 현재 수량×동일 통화 가격으로 평가한다.
실제 인증/운영 자료/보정 저장 검증은 별도다. 외화 현금 lot의 별도 환차손익은
아직 정책 미결정이며 거래별 환산 손익과 구분해 미지원으로 표시한다.
