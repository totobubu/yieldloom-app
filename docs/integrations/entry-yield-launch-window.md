# 과거 매수 시점별 배당률의 출시 이후 구간

이 카드는 매수 이후 실현 배당/총수익률이 아니라 **각 과거 가상 매수일에 알 수
있었던 배당과 그날 종가**의 비율이다. 분석일은 사용 가능한 가격·배당의 상한이며,
분자에 분석일까지의 미래 배당을 소급해 넣지 않는다.

- 12개월 표본: `[매수일 - 1년, 매수일)`의 배당 합계 × 0.85 ÷ 당시 종가 × 100.
- 출시 후 첫해 표본: `[공식 최초 거래일, 매수일)`의 검증된 배당 합계 × 0.85 ÷ 당시 종가 × 100.
- 후자는 **출시 이후 누적 배당률**로 표시하고 실제 시작·종료일을 함께 보여준다.
  연환산하거나 연간 배당/회수 연수로 표시하지 않는다. 기간 길이가 다른 누적
  표본임을 알리고, 12개월 표본과 같은 순위에 넣지 않는다. 적격 12개월 표본이
  있으면 해당 집합을 우선 사용하고, 없을 때에만 적격 첫해 표본을 표시한다.
- 배당락일은 매수일보다 앞서야 한다. 제공된 발표일이 매수일 당일/이후인 행,
  전망·미래 행은 사용하지 않는다. API는 발표일과 공식/교차 검증 여부를 보존한다.
- 첫해 누적에는 공식 배당 투영, 각 배당의 검증·발표일, 요청 기간 전체의 가격/배당
  coverage가 모두 필요하다. 누락·참고 자료·미확인 기간은 0으로 채우지 않는다.
  기존 장기 참고 계산의 경고와 분할/병합·충돌 차단은 유지한다.

## 출시 근거와 티커 변경

`lib/fund-lifecycle.js`의 검토된 최초 거래 근거만 기본으로 사용한다. 순수 계산의
`fundLifecycle` 응답과 `lifecycleEvidence` 옵션은 검토된 공급자 어댑터용 계약이다.
현재 기본 검토 목록은 TOPW이며 다른 종목도 검증된 계약이 제공되면 같은 계산을
사용한다. 근거가 없는 종목의 ipoDate를 자동으로 신뢰하지 않는다.
카탈로그의 단순 ipoDate, 펀드 설정일, 가격 수집 시작일 또는 사용자가 입력한
날짜를 이 근거로 자동 승격하지 않는다. 근거가 없는 종목은 보수적으로 보류한다.

TOPW의 [공식 상품 페이지](https://www.roundhillinvestments.com/etf/topw/)는 최초
거래일을 2025-09-04로, WPAY→TOPW 변경을 2026-03-20 거래 종료 후로 명시한다.
2026-11-03 검토. 티커 변경은 재출시가 아니며, WPAY 가격/배당을 자동 수집·병합하는
기능을 추가하지 않았다. 2026-11-03 분석일의 TOPW는 출시 후 이미 12개월이 지났다.

현재 공개 API 읽기 검증에서는 시세가 2025-09-04~2026-10-30, 배당은
2026-10-06~2026-11-03 다섯 건이고 collectionCoverage는 null이었다. 따라서 실제
TOPW는 이번 코드만으로 계산 가능해지지 않는다. 새 화면은 공식 최초 거래일,
티커 변경, 실제 수집 범위와 기간 검증 부족을 설명한다. 9월 정본 backfill은
별도 승인된 복구 작업으로 진행하며 이 코드 변경에 포함하지 않는다.

## 검증 범위

합성 신규 사례의 배당 3달러, 당시 종가 100달러는 누적 세후 2.55%이며 연환산
하지 않는다. 신규/오래된 펀드의 수집 누락, 미확인 출시일·설정일 오용, WPAY 연속성,
발표일·미래 자료·예측 제외, 지표 혼합 방지, 분할 차단을 회귀 검증한다.
브라우저는 같은 계산과 실제 카드 컴포넌트로 3개 출력 비율·계산 보류·티커 변경을
검증하며 API 요청과 페이지 오류가 없는지 확인한다. 운영 배당 정본·가격 원본·개인
장부·자격증명은 수정하지 않는다. 합성 신규 사례의 통과를 실제 TOPW 누락 해결로
표현하지 않는다.
