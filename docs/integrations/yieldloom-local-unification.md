## 운영 증분 호환 진단

2026-11-02 읽기 전용 검사에서 비공개 R2의 기존 배당 관측 3개는
`paymentStatus` 필드가 없는 구형 브라우저 원문임을 확인했다. 계좌 확인과
종목·통화·세전·세금·세후·입금 표시 시각·관측 시각은 정규화 관측과 일치했다.
현재 발행기는 새 자료에 두 위치의 명시적 `PAID`를 요구한다. 읽기 검증기는
아내 계좌의 2026-11-01 이전 관측 중 두 필드가 **모두 없는 경우**에만 별도의 입금 거래 상세 카드,
원본 문서 참조·금액·시각 검증을 계속 적용한다. 명시적 미지급 상태와 불완전한
상세 카드는 거부한다. 기존 원본·영수증·인덱스는 수정하지 않았다.
검증 결과에는 `paidEvidence.contract=toss-paid-detail-v1`과 해당 구형 상세
인정 건수를 기록하며, 새 관측에는 두 위치의 `PAID`를 계속 요구한다.
