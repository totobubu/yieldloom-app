# 증권사/은행/거래소 로고 이미지

이 폴더에는 증권사, 은행, 코인 거래소의 로고 이미지를 저장합니다.

## 파일명 관리

파일명은 `brokerages.json` 파일에서 관리됩니다. 이 JSON 파일에는 한국의 모든 증권사, 은행, 거래소 정보가 포함되어 있습니다.

## 파일명 규칙

- **파일 형식**: PNG (투명 배경 권장)
- **권장 크기**: 48x48px 이상 (정사각형)
- **파일명**: `brokerages.json`의 `fileName` 필드 참조

## brokerages.json 구조

```json
{
  "증권사": [
    {
      "name": "토스증권",
      "fileName": "toss-securities.png",
      "type": "증권"
    }
  ],
  "은행": [
    {
      "name": "KB국민은행",
      "fileName": "kb-bank.png",
      "type": "은행"
    }
  ],
  "거래소": [
    {
      "name": "업비트",
      "fileName": "upbit.png",
      "type": "거래소"
    }
  ]
}
```

## 로고 업로드 방법

1. `brokerages.json`에서 해당 증권사/은행/거래소의 `fileName` 확인
2. 로고 이미지를 해당 파일명으로 이 폴더에 저장
3. 예시:
   - 토스증권 → `toss-securities.png`
   - KB국민은행 → `kb-bank.png`
   - 업비트 → `upbit.png`
