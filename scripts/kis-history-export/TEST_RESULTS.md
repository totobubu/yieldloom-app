# 검증 결과

- 실행환경: 클라우드 Linux / Python. 실제 사용자 PC에서 실행한 결과가 아닙니다.
- `python -m unittest discover -s tests -v`: **26개 통과**.
- 검증 항목: 6년 72개월 분할 및 윤년/경계, 12페이지 연속조회, 재개 커서,
  중단/재시작 시 원문·중복·변경 관측 보존, 호출/인증 오류 중지,
  알 수 없는 응답과 반복 커서 거부, 빈 결과의 완전성 미확정 표시,
  소수 자릿수와 XLSX 텍스트 유지, CSV 수식 해석 방지,
  UTF-8 BOM/CRLF/`.txt` 설정 오류, 상품코드 미추측, 비밀값 비출력,
  HTTP 요청 규격의 fake transport 검사와 주문 경로 차단.
- 최신 범위 검증: 기본 시작일 없음, 종료일은 한국시간 실행일, 증빙 표본 월 및
  현재 월만 확인용으로 조회, 최초 반환 거래일과 실제 최초 거래일을 별도 표시,
  시작 경계 없는 전체 실행은 인증 전 중지, coverage gap을 명시.
- 독립 검증: `openpyxl`로 생성 XLSX를 다시 열어 고정밀 소수 문자열 및
  `=...` 값이 수식이 아닌 텍스트 셀로 유지됨을 확인했습니다.
  이 라이브러리는 검사에만 사용했으며 수집기에는 설치할 필요가 없습니다.
- 실제 KIS 인증/토큰 발급/계좌 조회: **미실행**.
- Windows CMD 실행 및 사용자 업무 PC 배치: **본 클라우드 작업에서 미실행**.
- 2020년 조회 지원, 미니스탁 포함, 전체 이력 완전성: **미확정**.
- R2 업로드, Git push, 배포: **미실행**. 이 패키지에 업로드 기능은 없습니다.
